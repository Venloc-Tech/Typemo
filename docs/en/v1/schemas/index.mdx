A schema in Typemo is a class with decorators. Both the runtime checks and the result types come from it. This section collects the guides on describing a model, from your first class and field types to indexes, hidden values, and collections with special properties. Every option of every decorator is listed in the [Schemas and models](../reference/schemas/index.mdx) reference.
