Sooner or later every application has to turn a refusal from the library or the database into a clear action or a response to the client. Typemo doesn't quietly fix bad input. It throws an error, and the edge of your application has to handle it. That's what this section is about. Every error class is described in detail in the [Errors](../reference/errors/index.mdx) reference.
