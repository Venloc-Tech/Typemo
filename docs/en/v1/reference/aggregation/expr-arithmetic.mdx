This page collects the arithmetic operators of the `fn` catalog. They add and multiply numbers, round them, raise them to powers, and take logarithms and trigonometric functions. An operator builds an expression, and the server evaluates it for every row of the pipeline. You write operators in stage callbacks such as [`project`](./stages.mdx#project) or [`group`](./stages.mdx#group), like this: `(f) => fn.add(f.price, 1)`. Here `f` is a proxy of the row's fields.

This is a reference. If you're starting out, read the guide [Calculations in aggregation](../../aggregation/expressions.mdx) first. Expressions are written only with a callback, and Typemo doesn't accept a raw object with `$expr`.

All examples use the same shop order model.

<Snippet id="reference/aggregation/expr-arithmetic/intro" title="models/order.ts" twoslash />

The collection holds one order.

- `title` is `"  Blue Pen  "` with spaces on both sides, and `sku` is `"PEN-001"`.
- `price` is 19.99, `quantity` is 3, `delta` is -5, and `ratio` is 0.5.
- `placedAt` is March 15, 2026, 10:30:45.123 UTC, and `shippedAt` is March 18, 2026, 08:00 UTC.
- `stamp` is a timestamp with seconds 1700000000 and increment 5.
- `tags` is `["new", "sale", "pen"]`, and `prices` is `[30, 10, 20]`.
- `lines` has two rows, `pen`×2 and `ink`×1.

The order has no `discount` field. The results in the `// →` comments come from running on this data.

## Rounding and absolute value [#rounding]

These operators take one number and return a number. For an integer, `ceil` and `floor` return the same integer.

One query computes all the operators of the group at once.

<Snippet id="reference/aggregation/expr-arithmetic/rounding" twoslash />

Each operator is described separately below.

### fn.abs [#fn.abs]

The absolute value of a number. `fn.abs(x)`.

For example, `fn.abs(f.delta)` gives `5`.

### fn.ceil [#fn.ceil]

The nearest integer not less than the number. `fn.ceil(x)`.

For example, `fn.ceil(f.price)` gives `20`.

### fn.floor [#fn.floor]

The nearest integer not greater than the number. `fn.floor(x)`.

For example, `fn.floor(f.price)` gives `19`.

### fn.round [#fn.round]

Rounds to `place` digits after the decimal point, to a whole number by default. A negative `place` rounds digits to the left of the point. Exactly half rounds to even. `fn.round(x, place?)`.

For example, `fn.round(f.price, 1)` gives `20`.

### fn.trunc [#fn.trunc]

Drops the fractional part. With `place`, it keeps that many digits after the decimal point. `fn.trunc(x, place?)`.

For example, `fn.trunc(f.price, 1)` gives `19.9`.

## Add, subtract, multiply, divide [#arithmetic]

The four arithmetic operations. If any argument is `null` or missing, the result is `null` too, and a gap doesn't turn into zero. The result type depends on the arguments: `number`, `bigint`, or `Decimal128`.

One query computes all the operators of the group at once.

<Snippet id="reference/aggregation/expr-arithmetic/arithmetic" twoslash />

Each operator is described separately below.

### fn.add [#fn.add]

The sum of two or more numbers. Adding a number of milliseconds to a date gives a date. `fn.add(a, b, …)`.

For example, `fn.add(f.price, f.quantity, 1)` gives `23.99`.

### fn.subtract [#fn.subtract]

The difference. Two dates give a difference in milliseconds (int64), and a date minus a number gives a date. `fn.subtract(a, b)`.

For example, `fn.subtract(f.shippedAt, f.placedAt)` gives `250154877n`.

### fn.multiply [#fn.multiply]

The product of two or more numbers. `fn.multiply(a, b, …)`.

For example, `fn.multiply(f.price, f.quantity)` gives `59.97`.

### fn.divide [#fn.divide]

The quotient. The server rejects division by zero with an error. `fn.divide(a, b)`.

For example, `fn.divide(f.price, f.quantity)` gives `6.663333333333333`.

### fn.mod [#fn.mod]

The remainder of a division. `fn.mod(a, b)`.

For example, `fn.mod(f.quantity, 2)` gives `1`.

## Powers and logarithms [#powers-and-logs]

These operators always return a floating-point number (`double`), or a `Decimal128` for a `Decimal128` argument.

One query computes all the operators of the group at once.

<Snippet id="reference/aggregation/expr-arithmetic/powers-and-logs" twoslash />

Each operator is described separately below.

### fn.sqrt [#fn.sqrt]

The square root. `fn.sqrt(x)`.

For example, `fn.sqrt(f.quantity)` gives `1.7320508075688772`.

### fn.pow [#fn.pow]

Raises to a power. `fn.pow(base, exponent)`.

For example, `fn.pow(f.quantity, 2)` gives `9`.

### fn.exp [#fn.exp]

The number e to the power x. `fn.exp(x)`.

For example, `fn.exp(1)` gives `2.718281828459045`.

### fn.ln [#fn.ln]

The natural logarithm. `fn.ln(x)`.

For example, `fn.ln(10)` gives `2.302585092994046`.

### fn.log [#fn.log]

The logarithm to a given base. `fn.log(x, base)`.

For example, `fn.log(8, 2)` gives `3`.

### fn.log10 [#fn.log10]

The base-10 logarithm. `fn.log10(x)`.

For example, `fn.log10(1000)` gives `3`.

## Trigonometry [#trigonometry]

The trigonometric functions take radians and return a floating-point number. If a value is outside the function's domain, for example `asin(2)`, the server answers with an error.

One query computes all the operators of the group at once.

<Snippet id="reference/aggregation/expr-arithmetic/trigonometry" twoslash />

Each operator is described separately below.

### fn.sin [#fn.sin]

The sine. `fn.sin(x)`.

For example, `fn.sin(f.ratio)` gives `0.479425538604203`.

### fn.cos [#fn.cos]

The cosine. `fn.cos(x)`.

For example, `fn.cos(f.ratio)` gives `0.8775825618903728`.

### fn.tan [#fn.tan]

The tangent. `fn.tan(x)`.

For example, `fn.tan(f.ratio)` gives `0.5463024898437905`.

### fn.asin [#fn.asin]

The arcsine. The argument ranges from -1 to 1. `fn.asin(x)`.

For example, `fn.asin(f.ratio)` gives `0.5235987755982988`.

### fn.acos [#fn.acos]

The arccosine. The argument ranges from -1 to 1. `fn.acos(x)`.

For example, `fn.acos(f.ratio)` gives `1.0471975511965976`.

### fn.atan [#fn.atan]

The arctangent. `fn.atan(x)`.

For example, `fn.atan(f.ratio)` gives `0.46364760900080615`.

### fn.atan2 [#fn.atan2]

The arctangent of y/x, taking the quadrant into account. `fn.atan2(y, x)`.

For example, `fn.atan2(1, 1)` gives `0.7853981633974483`.

### fn.sinh [#fn.sinh]

The hyperbolic sine. `fn.sinh(x)`.

For example, `fn.sinh(f.ratio)` gives `0.5210953054937474`.

### fn.cosh [#fn.cosh]

The hyperbolic cosine. `fn.cosh(x)`.

For example, `fn.cosh(f.ratio)` gives `1.1276259652063807`.

### fn.tanh [#fn.tanh]

The hyperbolic tangent. `fn.tanh(x)`.

For example, `fn.tanh(f.ratio)` gives `0.46211715726000974`.

### fn.asinh [#fn.asinh]

The inverse hyperbolic sine. `fn.asinh(x)`.

For example, `fn.asinh(f.ratio)` gives `0.48121182505960347`.

### fn.acosh [#fn.acosh]

The inverse hyperbolic cosine. The argument is at least 1. `fn.acosh(x)`.

For example, `fn.acosh(2)` gives `1.3169578969248166`.

### fn.atanh [#fn.atanh]

The inverse hyperbolic tangent. The argument ranges from -1 to 1. `fn.atanh(x)`.

For example, `fn.atanh(f.ratio)` gives `0.5493061443340549`.

### fn.degreesToRadians [#fn.degrees-to-radians]

Converts degrees to radians. `fn.degreesToRadians(x)`.

For example, `fn.degreesToRadians(180)` gives `3.141592653589793`.

### fn.radiansToDegrees [#fn.radians-to-degrees]

Converts radians to degrees. `fn.radiansToDegrees(x)`.

For example, `fn.radiansToDegrees(1)` gives `57.29577951308232`.

### fn.sigmoid [#fn.sigmoid]

The sigmoid `1 / (1 + e^-x)`. It squeezes any number into the interval from 0 to 1. `fn.sigmoid(x)`.

For example, `fn.sigmoid(0)` gives `0.5`.

## Special cases [#special-cases]

If an argument is missing or `null`, the result is `null`. For an order without `discount`, the expression `fn.add(f.price, f.discount)` gives `null`, not 19.99. The server rejects division by zero.

<Snippet id="reference/aggregation/expr-arithmetic/special-cases" />

`fn.round` rounds exactly half to even. `fn.round(2.5)` gives 2, `fn.round(3.5)` gives 4, and `fn.round(1234, -2)` gives 1200. Don't count on rounding away from zero.

## When not to use it [#when-not-to-use]

To reduce numbers across a group of rows instead of computing within one row, use the accumulators [`fn.sum` and `fn.avg`](./accumulators.mdx) in [`group`](./stages.mdx#group). Type conversion (`toInt`, `toDouble`) is covered on the page about [type conversion](./expr-conversion.mdx).
