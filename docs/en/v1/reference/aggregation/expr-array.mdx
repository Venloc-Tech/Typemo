This page collects the `fn` operators for working with arrays inside a single row. They pick elements by index, cut slices, compute sets, and offer `map`, `filter`, and `reduce`. The server computes them for every row in stages such as [`project`](./stages.mdx#project) or [`addFields`](./stages.mdx#add-fields).

This is a reference. If you're starting out, read the guide [Calculations in aggregation](../../aggregation/expressions.mdx) first. Expressions are written only with a callback, and Typemo doesn't accept a raw object with `$expr`.

All examples use the same shop order model.

<Snippet id="reference/aggregation/expr-arithmetic/intro" title="models/order.ts" twoslash />

The collection holds one order.

- `title` is `"  Blue Pen  "` with spaces on both sides, and `sku` is `"PEN-001"`.
- `price` is 19.99, `quantity` is 3, `delta` is -5, and `ratio` is 0.5.
- `placedAt` is March 15, 2026, 10:30:45.123 UTC, and `shippedAt` is March 18, 2026, 08:00 UTC.
- `stamp` is a timestamp with seconds 1700000000 and increment 5.
- `tags` is `["new", "sale", "pen"]`, and `prices` is `[30, 10, 20]`.
- `lines` has two rows, `pen`×2 and `ink`×1.

The order has no `discount` field. The results in the `// →` comments come from running on this data.

## Size, order, and access [#size-order-access]

These operators read an array and don't change it. For `null` and a missing field, most of them return `null`, while `size` fails on a non-array.

One query computes all the operators of the group at once.

<Snippet id="reference/aggregation/expr-array/size-order-access" twoslash />

Each operator is described separately below.

### fn.size [#fn.size]

The number of elements. On a non-array, the server answers with an error. `fn.size(array)`.

For example, `fn.size(f.tags)` gives `3`.

### fn.arrayElemAt [#fn.array-elem-at]

The element at an index. A negative index counts from the end, and an index out of bounds gives a missing value. `fn.arrayElemAt(array, index)`.

For example, `fn.arrayElemAt(f.tags, 0)` gives `"new"`.

### fn.indexOfArray [#fn.index-of-array]

The index of a value, or `-1` if it isn't there. `fn.indexOfArray(array, value, from?, to?)`.

For example, `fn.indexOfArray(f.tags, "sale")` gives `1`.

### fn.slice [#fn.slice]

A slice. It takes the first `n` elements (the last ones for a negative `n`), or `n` elements from a given position. `fn.slice(array, n)` and `fn.slice(array, position, n)`.

For example, `fn.slice(f.tags, 1, 1)` gives `["sale"]`.

### fn.reverseArray [#fn.reverse-array]

The array in reverse order. `fn.reverseArray(array)`.

For example, `fn.reverseArray(f.tags)` gives `["pen", "sale", "new"]`.

### fn.sortArray [#fn.sort-array]

Sorts an array. For numbers and strings, `sortBy` is `1` or `-1`, and for documents it's an object by fields. `fn.sortArray({ input, sortBy })`.

For example, `fn.sortArray({ input: f.prices, sortBy: 1 })` gives `[10, 20, 30]`.

### fn.range [#fn.range]

Integers from `start` to `end`, not including `end` itself. The `step` defaults to 1. `fn.range(start, end, step?)`.

For example, `fn.range(0, 5, 2)` gives `[0, 2, 4]`.

## Union and sets [#union-and-sets]

For set operators, an array is a collection of unique values with no order. The result of `setUnion` and similar operators has no repeats, and the server doesn't promise an order.

One query computes all the operators of the group at once.

<Snippet id="reference/aggregation/expr-array/union-and-sets" twoslash />

Each operator is described separately below.

### fn.concatArrays [#fn.concat-arrays]

Joins arrays. `fn.concatArrays(a, b, …)`.

For example, `fn.concatArrays(f.tags, ["x"])` gives `["new", "sale", "pen", "x"]`.

### fn.setUnion [#fn.set-union]

The union of sets. `fn.setUnion(a, b, …)`.

For example, `fn.setUnion(f.tags, ["sale", "big"])` gives `["big", "new", "pen", "sale"]`.

### fn.setIntersection [#fn.set-intersection]

The intersection of sets. `fn.setIntersection(a, b, …)`.

For example, `fn.setIntersection(f.tags, ["sale", "x"])` gives `["sale"]`.

### fn.setDifference [#fn.set-difference]

The elements of the first array that aren't in the second. `fn.setDifference(a, b)`.

For example, `fn.setDifference(f.tags, ["sale"])` gives `["new", "pen"]`.

### fn.setIsSubset [#fn.set-is-subset]

Checks that every element of the first array is in the second. `fn.setIsSubset(a, b)`.

For example, `fn.setIsSubset(["sale"], f.tags)` gives `true`.

### fn.setEquals [#fn.set-equals]

Checks that the sets consist of the same values. `fn.setEquals(a, b, …)`.

For example, `fn.setEquals(f.tags, ["pen", "sale", "new"])` gives `true`.

### fn.zip [#fn.zip]

Transposes arrays and builds pairs of elements with the same index. With `useLongestLength`, shorter arrays are padded with the `defaults` values. `fn.zip({ inputs, useLongestLength?, defaults? })`.

For example, `fn.zip({ inputs: [f.tags, f.prices] })` gives `[["new", 30], ["sale", 10], ["pen", 20]]`.

## Checks and transforms [#validation-and-transforms]

These operators work element by element. `map` applies an expression to each one, `filter` keeps the matching ones, and `reduce` folds an array into one value. Inside the callback, the element is a proxy, like the field `f`.

One query computes all the operators of the group at once.

<Snippet id="reference/aggregation/expr-array/validation-and-transforms" twoslash />

Each operator is described separately below.

### fn.allElementsTrue [#fn.all-elements-true]

Checks that all elements are truthy. An empty array gives `true`. `fn.allElementsTrue(array)`.

For example, `fn.allElementsTrue(f.prices)` gives `true`.

### fn.anyElementTrue [#fn.any-element-true]

Checks that at least one element is truthy. An empty array gives `false`. `fn.anyElementTrue(array)`.

For example, `fn.anyElementTrue(f.prices)` gives `true`.

### fn.map [#fn.map]

Applies an expression to each element. `fn.map({ input, in: (item) => … })`.

For example, `fn.map({ input: f.prices, in: (price) => fn.multiply(price, 2) })` gives `[60, 20, 40]`.

### fn.filter [#fn.filter]

Keeps the elements for which `cond` is true. `limit` caps how many it keeps. `fn.filter({ input, cond: (item) => …, limit? })`.

For example, `fn.filter({ input: f.prices, cond: (price) => fn.gt(price, 15) })` gives `[30, 20]`.

### fn.reduce [#fn.reduce]

Folds an array. The result type matches the type of `initialValue`. `fn.reduce({ input, initialValue, in: (acc, item) => … })`.

For example, `fn.reduce({ input: f.prices, initialValue: 0, in: (acc, price) => fn.add(acc, price) })` gives `60`.

### fn.arrayToObject [#fn.array-to-object]

Turns an array of `{ k, v }` or `[k, v]` pairs into a document. `fn.arrayToObject(array)`.

For example, `fn.arrayToObject(fn.map({ input: f.lines, in: (line) => ({ k: line.sku, v: line.qty }) }))` gives `{pen: 2, ink: 1}`.

## Special cases [#special-cases]

The server rejects `fn.size` on a non-array. For a string, the answer is `The argument to $size must be an array, but was of type: string`. That's why `size` accepts only array fields, and the compiler stops a call on a string.

## When not to use it [#when-not-to-use]

To turn array elements into separate rows, use the [`unwind`](./stages.mdx#unwind) stage. To collect values from many rows into an array, use the accumulators `fn.push` and `fn.addToSet` in [`group`](./stages.mdx#group).
