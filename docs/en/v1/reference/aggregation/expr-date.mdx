This page collects the `fn` operators for working with dates. They extract date parts, add and subtract, round, build, parse, and format. The server computes the values for every row inside a stage such as [`project`](./stages.mdx#project). Without `timezone`, everything is computed in UTC. You can set a time zone by name (`"Asia/Tokyo"`) or by offset.

This is a reference. If you're starting out, read the guide [Calculations in aggregation](../../aggregation/expressions.mdx) first. Expressions are written only with a callback, and Typemo doesn't accept a raw object with `$expr`.

All examples use the same shop order model.

<Snippet id="reference/aggregation/expr-arithmetic/intro" title="models/order.ts" twoslash />

The collection holds one order.

- `title` is `"  Blue Pen  "` with spaces on both sides, and `sku` is `"PEN-001"`.
- `price` is 19.99, `quantity` is 3, `delta` is -5, and `ratio` is 0.5.
- `placedAt` is March 15, 2026, 10:30:45.123 UTC, and `shippedAt` is March 18, 2026, 08:00 UTC.
- `stamp` is a timestamp with seconds 1700000000 and increment 5.
- `tags` is `["new", "sale", "pen"]`, and `prices` is `[30, 10, 20]`.
- `lines` has two rows, `pen`×2 and `ink`×1.

The order has no `discount` field. The results in the `// →` comments come from running on this data.

## Date parts [#date-parts]

An operator accepts a date or an object `{ date, timezone }`. Without `timezone`, parts are computed in UTC. For `null` and a missing field, the result is `null`.

One query computes all the operators of the group at once.

<Snippet id="reference/aggregation/expr-date/date-parts" twoslash />

Each operator is described separately below.

### fn.year [#fn.year]

The year. `fn.year(date)`.

For example, `fn.year(f.placedAt)` gives `2026`.

### fn.month [#fn.month]

The month, from 1 to 12. `fn.month(date)`.

For example, `fn.month(f.placedAt)` gives `3`.

### fn.dayOfMonth [#fn.day-of-month]

The day of the month. `fn.dayOfMonth(date)`.

For example, `fn.dayOfMonth(f.placedAt)` gives `15`.

### fn.hour [#fn.hour]

The hour, from 0 to 23. `fn.hour(date)`.

For example, `fn.hour(f.placedAt)` gives `10`.

### fn.minute [#fn.minute]

The minute. `fn.minute(date)`.

For example, `fn.minute(f.placedAt)` gives `30`.

### fn.second [#fn.second]

The second. `fn.second(date)`.

For example, `fn.second(f.placedAt)` gives `45`.

### fn.millisecond [#fn.millisecond]

The millisecond. `fn.millisecond(date)`.

For example, `fn.millisecond(f.placedAt)` gives `123`.

### fn.dayOfWeek [#fn.day-of-week]

The day of the week, where Sunday is 1. `fn.dayOfWeek(date)`.

For example, `fn.dayOfWeek(f.placedAt)` gives `1`.

### fn.dayOfYear [#fn.day-of-year]

The day of the year, from 1 to 366. `fn.dayOfYear(date)`.

For example, `fn.dayOfYear(f.placedAt)` gives `74`.

### fn.week [#fn.week]

The week of the year, from 0 to 53. A week starts on Sunday. `fn.week(date)`.

For example, `fn.week(f.placedAt)` gives `11`.

### fn.isoWeek [#fn.iso-week]

The ISO 8601 week of the year, from 1 to 53. `fn.isoWeek(date)`.

For example, `fn.isoWeek(f.placedAt)` gives `11`.

### fn.isoWeekYear [#fn.iso-week-year]

The year by ISO weeks. The server returns int64, so the type is `bigint`. `fn.isoWeekYear(date)`.

For example, `fn.isoWeekYear(f.placedAt)` gives `2026n`.

### fn.isoDayOfWeek [#fn.iso-day-of-week]

The ISO day of the week, where Monday is 1. `fn.isoDayOfWeek(date)`.

For example, `fn.isoDayOfWeek(f.placedAt)` gives `7`.

## Date arithmetic [#date-arithmetic]

All operators of the group take an object. The `unit` is one of `year`, `quarter`, `week`, `month`, `day`, `hour`, `minute`, `second`, or `millisecond`. With `timezone`, day and month boundaries are computed in that time zone, and daylight saving transitions are taken into account.

One query computes all the operators of the group at once.

<Snippet id="reference/aggregation/expr-date/date-arithmetic" twoslash />

Each operator is described separately below.

### fn.dateAdd [#fn.date-add]

Adds `amount` units to a date. `fn.dateAdd({ startDate, unit, amount, timezone? })`.

For example, `fn.dateAdd({ startDate: f.placedAt, unit: "day", amount: 7 })` gives `new Date("2026-03-22T10:30:45.123Z")`.

### fn.dateSubtract [#fn.date-subtract]

Subtracts `amount` units. `fn.dateSubtract({ startDate, unit, amount, timezone? })`.

For example, `fn.dateSubtract({ startDate: f.placedAt, unit: "month", amount: 1 })` gives `new Date("2026-02-15T10:30:45.123Z")`.

### fn.dateDiff [#fn.date-diff]

Counts how many unit boundaries lie between two dates. The result is int64, so the type is `bigint`. Say a minute before midnight on March 15 and a minute after it: one day boundary lies between them. `fn.dateDiff({ startDate, endDate, unit, timezone?, startOfWeek? })`.

For example, `fn.dateDiff({ startDate: f.placedAt, endDate: f.shippedAt, unit: "day" })` gives `3n`.

### fn.dateTrunc [#fn.date-trunc]

Rounds down to the start of a unit, or to the start of `binSize` units. `fn.dateTrunc({ date, unit, binSize?, timezone?, startOfWeek? })`.

For example, `fn.dateTrunc({ date: f.placedAt, unit: "month" })` gives `new Date("2026-03-01T00:00:00.000Z")`.

## Build, parse, and format [#build-parse-format]

These operators turn a date into parts or a string and back.

One query computes all the operators of the group at once.

<Snippet id="reference/aggregation/expr-date/build-parse-format" twoslash />

Each operator is described separately below.

### fn.dateFromParts [#fn.date-from-parts]

Builds a date from parts. Only `year` is required, and the other parts default to the start of the period. Instead of calendar parts, you can pass ISO weeks (`isoWeekYear`, `isoWeek`, `isoDayOfWeek`). `fn.dateFromParts({ year, month?, day?, hour?, minute?, second?, millisecond?, timezone? })`.

For example, `fn.dateFromParts({ year: 2026, month: 3, day: 15 })` gives `new Date("2026-03-15T00:00:00.000Z")`.

### fn.dateToParts [#fn.date-to-parts]

Splits a date into parts. With `iso8601: true`, it splits into ISO parts (`isoWeekYear`, `isoWeek`, `isoDayOfWeek`). `fn.dateToParts({ date, timezone?, iso8601? })`.

For example, `fn.dateToParts({ date: f.placedAt })` gives `{year: 2026, month: 3, day: 15, hour: 10, minute: 30, second: 45, millisecond: 123}`.

### fn.dateFromString [#fn.date-from-string]

Parses a string into a date. `onError` and `onNull` set the value for an invalid or empty string. Without `onError`, an invalid string is a server error. `fn.dateFromString({ dateString, format?, timezone?, onError?, onNull? })`.

For example, `fn.dateFromString({ dateString: "2026-03-15", onError: null })` gives `new Date("2026-03-15T00:00:00.000Z")`.

### fn.dateToString [#fn.date-to-string]

Formats a date as a string. Without `format`, you get ISO 8601. `onNull` replaces `null`. `fn.dateToString({ date, format?, timezone?, onNull? })`.

For example, `fn.dateToString({ date: f.placedAt, format: "%Y-%m-%d" })` gives `"2026-03-15"`.

## Timestamps [#timestamps]

`Timestamp` is an internal MongoDB type, a pair of seconds and an increment. The operators extract its parts, and both parts are int64.

One query computes all the operators of the group at once.

<Snippet id="reference/aggregation/expr-date/timestamps" twoslash />

Each operator is described separately below.

### fn.tsSecond [#fn.ts-second]

The seconds of a timestamp (int64, `bigint`). `fn.tsSecond(timestamp)`.

For example, `fn.tsSecond(f.stamp)` gives `1700000000n`.

### fn.tsIncrement [#fn.ts-increment]

The increment of a timestamp (int64, `bigint`). `fn.tsIncrement(timestamp)`.

For example, `fn.tsIncrement(f.stamp)` gives `5n`.

## Time zones [#time-zones]

Date parts accept an object `{ date, timezone }`. The same moment in Tokyo is already 19:00. `fn.hour({ date: f.placedAt, timezone: "Asia/Tokyo" })` gives `19`, and without a time zone it gives `10`. You need a time zone when the "order day" must match the buyer's day, not the UTC day.

## When not to use it [#when-not-to-use]

To group orders by month, use [`dateTrunc`](#fn.date-trunc) in the `_id` of the [`group`](./stages.mdx#group) stage. Gaps in a series of dates are filled by the [`densify`](./stages.mdx#densify) stage, not by operators.
