The Aggregation reference describes every API element in full: what it accepts, what it returns, and which errors it throws. If your question is "how do I do X", start with the [section guides](../../aggregation/index.mdx). They go from the task to the solution and send you here for details.

The pages follow the structure of a pipeline. Entry points and stages come first, then expression operators by topic, and accumulators and window functions last. Every `fn` operator is described in its own `### fn.name` section.
