The reference describes every element of the public API in full. What it accepts, what it returns, which errors it throws, and when it doesn't fit: it's all here. The sections mirror the guides, so the guide `queries/…` matches the reference `reference/query/…`. If you're solving a task and don't know where to start, open the guides from ["Getting started"](../getting-started/index.mdx). They go from the task to the solution and send you here for details.

Every reference page opens with an overview, and the elements on it follow one template. Once you've read one page, you know where to look on any other. For an unfamiliar word, see the [glossary](../appendix/glossary.mdx).
