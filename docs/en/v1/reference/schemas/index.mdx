This section describes everything a model is built from. That means the `@Schema` and `@Prop` decorators with all their options, field types, base classes, virtual references, discriminators, indexes, and reading the schema at runtime. If you're just starting, read the guides of the "Schemas and models" section first. Open the reference when you need to check a detail.
