Sometimes several writes have to go through together or not at all. A transfer between accounts, an order with its line items, an invoice and its journal entry: half of such a change is worse than none. The guides here cover exactly these tasks.

Transactions need a replica set (several MongoDB servers holding copies of the same data, though one server is enough for transactions) or a sharded cluster. Every method and setting is described in the [section reference](../reference/transactions/index.mdx).
