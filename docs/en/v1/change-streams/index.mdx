---
title: Change streams
description: "Get an event for every insert, update, replace, and delete, and don't lose events after a stop"
icon: Radio
---

MongoDB can send you an event for every write to a collection. Your app reacts to it right away instead of polling the database on a timer. These change streams work on a replica set and see only what happened after they were opened. The exact types and errors are in the [reference](../reference/change-streams/index.mdx).
