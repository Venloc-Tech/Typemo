A **hook** is a model method that Typemo calls before or after an operation or a document event. Use a hook when a rule has to apply to every path to the data at once: a shared read condition, a field cast before saving, or a log of results. A **plugin** gathers such rules in one place and plugs into many models. Every element is described in full in the [section reference](../reference/hooks/index.mdx).
