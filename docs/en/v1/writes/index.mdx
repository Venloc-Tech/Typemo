This section is all about writes: create documents, change them with operators or a pipeline, replace them whole, delete them, and send many operations in one request. Typemo checks every write before it goes to the database. It stops dangerous ones, such as an empty filter in an update or a delete, with an error. Every method is described in the [section reference](../reference/writes/index.mdx).
