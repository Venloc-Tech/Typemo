`@venloc/typemo-nestjs` plugs Typemo into a NestJS 12 application. The client connects on startup and closes on shutdown. Models are injected by entity class with full types, a transaction is declared with a method decorator, and the tenant comes from the request. Database errors turn into HTTP responses that don't leak anything they shouldn't.

The package fully replaces `@nestjs/mongoose` and doesn't depend on Mongoose.
