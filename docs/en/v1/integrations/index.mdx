title: Integrations

icon: Boxes
---

An integration plugs Typemo into a framework's lifecycle. The client is created and closed together with the application, models are injected as dependencies, and errors turn into responses. Each integration is a separate package. The core `@venloc/typemo` knows nothing about frameworks, so an application without one doesn't pull in anything extra.
