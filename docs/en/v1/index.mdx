**Typemo** is an ODM for MongoDB in TypeScript, written from scratch. You describe a schema as a class with decorators, and the types of models, queries, and results come from that same class. They aren't glued on top of someone else's runtime.

Strictness here is absolute. An unknown field, `undefined` in a filter, or an empty filter in a write is an error, not silent behavior. No option and no mode relaxes it. Typemo talks to the database through the official `mongodb` driver and works only with the latest versions of MongoDB, the driver, `bson`, Bun, and TypeScript.

## What it looks like [#overview]

The class describes an account once. From then on the compiler knows which fields the model has, which of them you can select, and what comes back. Look at the type of `rows`. After `select` and `plain` it has only `_id` and `title`, and `_id` is already a string you can send to a client.

<Snippet id="index/overview" twoslash />

A typo in a field name won't compile. And if someone gets around the types, the query fails before it reaches the database. [What is Typemo](./concepts/what-is-typemo.mdx) explains how this works.

## Supported versions [#supported-versions]

Typemo is tested on MongoDB `8.3` and `9.0.0-rc0`, the `mongodb` driver `7.6.0`, `bson` `7.3.3`, Bun `1.4.0`, and TypeScript `6.0.3`. Older versions aren't supported. On Node.js only a smoke test of the built package has been run. The full list, and everything that wasn't tested, is in [Version compatibility](./appendix/versions.mdx).
