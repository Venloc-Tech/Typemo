`@venloc/typemo-nestjs` встраивает Typemo в приложение на NestJS 12: клиент подключается при старте и закрывается при остановке, модели внедряются по классу сущности с полными типами, транзакции объявляются декоратором метода, тенант берётся из запроса, а ошибки базы превращаются в ответы HTTP без утечки внутренностей. Пакет заменяет `@nestjs/mongoose` целиком и не зависит от Mongoose.
