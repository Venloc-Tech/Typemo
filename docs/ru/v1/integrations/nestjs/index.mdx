`@venloc/typemo-nestjs` встраивает Typemo в приложение на NestJS 12. Клиент подключается при старте и закрывается при остановке. Модели внедряются по классу сущности с полными типами, транзакция объявляется декоратором метода, а тенант берётся из запроса. Ошибки базы превращаются в ответы HTTP и не выдают наружу ничего лишнего.

Пакет целиком заменяет `@nestjs/mongoose` и от Mongoose не зависит.
