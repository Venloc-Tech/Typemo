Иногда значение поля нужно показать, но не целиком. Тогда замаскируйте его. [`.mask`](../reference/query/masks.mdx#mask) превращает `alice@gmail.com` в `a***@gmail.com`, а номер карты — в `************4242`. Сотруднику поддержки важно понять, о какой карте речь, а полный номер ему видеть незачем. Маска действует на то, что получит вызывающий код, а данные в базе и в памяти приложения остаются настоящими.

Если поле клиенту не нужно вовсе, лучше его не читать. Для этого есть [`.select`](../reference/query/reading.mdx#select) и [`hidden`](../reference/schemas/prop.mdx#hidden). Маска нужна, когда надо «показать часть».

## Что понадобится

Клиент из руководства [Подключиться к базе](../connection/connect.mdx) и модель клиента магазина из файла `customers/customer.ts`.

```ts twoslash title="customers/customer.ts"
import { Entity, Prop, Schema, Spec } from "@venloc/typemo";

@Schema()
export class Card {
  @Prop(() => String, { required: true })
  number!: string;

  @Prop(() => String)
  holder?: string;
}

@Schema({ collection: "customers" })
export class Customer extends Entity {
  @Prop(() => String, { required: true })
  name!: string;

  @Prop(() => String, { required: true })
  email!: string;

  @Prop(() => String, { nullable: true })
  phone!: string | null;

  @Prop(() => Number)
  age?: number;

  @Prop(() => [Card])
  cards!: Card[];

  @Prop(() => Spec.map(String))
  notes?: Map<string, string>;
}
```

В коллекции два клиента.

- Alice — почта `alice@gmail.com`, телефон `+79161234567`, 30 лет. У неё две карты, `4242 4242 4242 4242` с владельцем `Alice A` и `5555 5555 5555 4444` без владельца, и заметка `vip` со значением `yes`.
- Bob — почта `bob@example.org`, телефон `null`, 17 лет, карт нет.

## Быстрый путь

Два самых частых случая. Первый — маска у запроса. Вы передаёте объект «путь → маска», где маска — готовая из набора [`Mask`](../reference/query/masks.mdx#пресеты-mask) или строка `"mask"`.

```ts twoslash
import { Entity, Mask, Prop, Schema, Spec, TypemoClient } from "@venloc/typemo";
@Schema()
class Card { @Prop(() => String, { required: true }) number!: string; @Prop(() => String) holder?: string; }
@Schema({ collection: "customers" })
class Customer extends Entity {
  @Prop(() => String, { required: true }) name!: string;
  @Prop(() => String, { required: true }) email!: string;
  @Prop(() => String, { nullable: true }) phone!: string | null;
  @Prop(() => Number) age?: number;
  @Prop(() => [Card]) cards!: Card[];
  @Prop(() => Spec.map(String)) notes?: Map<string, string>;
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
const Customers = client.db().model(Customer);
// ---cut---
const rows = await Customers.find().sort({ name: 1 }).plain().mask({ email: Mask.email(), phone: Mask.phone() });
console.log(rows.map((row) => [row.email, row.phone]));
// → [["a***@gmail.com", "+7********67"], ["b***@example.org", "?"]]
```

Второй — маска у уже загруженного документа, через параметр `mask` его сериализации.

```ts twoslash
import { Entity, Mask, Prop, Schema, Spec, TypemoClient } from "@venloc/typemo";
@Schema()
class Card { @Prop(() => String, { required: true }) number!: string; @Prop(() => String) holder?: string; }
@Schema({ collection: "customers" })
class Customer extends Entity {
  @Prop(() => String, { required: true }) name!: string;
  @Prop(() => String, { required: true }) email!: string;
  @Prop(() => String, { nullable: true }) phone!: string | null;
  @Prop(() => Number) age?: number;
  @Prop(() => [Card]) cards!: Card[];
  @Prop(() => Spec.map(String)) notes?: Map<string, string>;
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
const Customers = client.db().model(Customer);
// ---cut---
const alice = await Customers.findOne({ name: "Alice" }).orFail();
console.log(alice.$toPlain({ mask: { email: Mask.email() } }).email);
// → "a***@gmail.com"
```

Ниже разберём каждый вариант на задачах.

## Показать сотруднику поддержки часть данных

Допустим, страница поддержки показывает почту, телефон и возраст клиента, но не полностью. Маска применяется **последним шагом** — после чтения, подстановки связанных документов и превращения в обычные объекты. Поэтому её вызывают после [`.plain()`](../reference/query/reading.mdx#plain) или [`.lean()`](../reference/query/reading.mdx#lean).

```ts twoslash title="customers/support.service.ts"
import { Entity, Mask, Prop, Schema, Spec, TypemoClient } from "@venloc/typemo";
@Schema()
class Card { @Prop(() => String, { required: true }) number!: string; @Prop(() => String) holder?: string; }
@Schema({ collection: "customers" })
class Customer extends Entity {
  @Prop(() => String, { required: true }) name!: string;
  @Prop(() => String, { required: true }) email!: string;
  @Prop(() => String, { nullable: true }) phone!: string | null;
  @Prop(() => Number) age?: number;
  @Prop(() => [Card]) cards!: Card[];
  @Prop(() => Spec.map(String)) notes?: Map<string, string>;
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
const Customers = client.db().model(Customer);
// ---cut---
export const listForSupport = () =>
  Customers.find()
    .sort({ name: 1 })
    .plain()
    .mask({ email: Mask.email(), phone: Mask.phone(), age: Mask.bucket([18, 35, 60]) });

const customers = await listForSupport();
console.log(customers.map((customer) => [customer.email, customer.phone, customer.age]));
// → [["a***@gmail.com", "+7********67", "18–35"], ["b***@example.org", "?", "<18"]]
```

`Mask.bucket([18, 35, 60])` превращает возраст в подпись диапазона. 30 попадает в `"18–35"`, 17 — в `"<18"`.

Телефон Bob был `null`, а стал `"?"`. Для `null` и `undefined` в маскируемом поле маска не вызывается, такие значения всегда заменяются на `"?"`. Поэтому по маске не отличить «значения нет» от «значение скрыто». Зато функции маски не нужно проверять `null`.

Тип результата тоже изменился, и компилятор об этом знает.

```ts twoslash
import { Entity, Mask, Prop, Schema, Spec, TypemoClient } from "@venloc/typemo";
@Schema()
class Card { @Prop(() => String, { required: true }) number!: string; @Prop(() => String) holder?: string; }
@Schema({ collection: "customers" })
class Customer extends Entity {
  @Prop(() => String, { required: true }) name!: string;
  @Prop(() => String, { required: true }) email!: string;
  @Prop(() => String, { nullable: true }) phone!: string | null;
  @Prop(() => Number) age?: number;
  @Prop(() => [Card]) cards!: Card[];
  @Prop(() => Spec.map(String)) notes?: Map<string, string>;
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
const Customers = client.db().model(Customer);
// ---cut---
const rows = await Customers.find().plain().mask({ email: Mask.email(), age: "mask" });
const first = rows[0];
console.log(first?.age);
//                 ^?
```

Поле с `"mask"` получило тип `"?"`, а поле с готовой маской — `SensitiveJson`, то есть любое JSON-значение, ведь маска вправе вернуть и строку, и объект. Пути компилятор тоже проверяет. Опечатка в имени поля не скомпилируется, а маска для числа не подойдёт к строковому полю.

## Замаскировать вложенные значения

Путь через массив проходит по каждому элементу, так что `cards.number` маскирует номер каждой карты. Значения словаря маскируются через `$*`. Ключ остаётся, маскируется только значение.

```ts twoslash
import { Entity, Mask, Prop, Schema, Spec, TypemoClient } from "@venloc/typemo";
@Schema()
class Card { @Prop(() => String, { required: true }) number!: string; @Prop(() => String) holder?: string; }
@Schema({ collection: "customers" })
class Customer extends Entity {
  @Prop(() => String, { required: true }) name!: string;
  @Prop(() => String, { required: true }) email!: string;
  @Prop(() => String, { nullable: true }) phone!: string | null;
  @Prop(() => Number) age?: number;
  @Prop(() => [Card]) cards!: Card[];
  @Prop(() => Spec.map(String)) notes?: Map<string, string>;
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
const Customers = client.db().model(Customer);
// ---cut---
const [alice] = await Customers.find({ name: "Alice" }).plain().mask({
  "cards.number": Mask.card(),
  "cards.holder": Mask.initials(),
  "notes.$*": "mask",
});
console.log(alice?.cards, [...(alice?.notes ?? [])]);
// → [{ number: "************4242", holder: "A. A." }, { number: "************4444" }] [["vip", "?"]]
```

У второй карты владельца нет, и в результате его тоже нет. Отсутствующее поле остаётся отсутствующим, маска его не выдумывает.

## Своя маска

Если готовых масок мало, передайте функцию. Она получает настоящее значение и возвращает то, что увидит вызывающий код. Вызывается функция только для значений, которые есть.

```ts twoslash
import { Entity, Mask, Prop, Schema, Spec, TypemoClient } from "@venloc/typemo";
@Schema()
class Card { @Prop(() => String, { required: true }) number!: string; @Prop(() => String) holder?: string; }
@Schema({ collection: "customers" })
class Customer extends Entity {
  @Prop(() => String, { required: true }) name!: string;
  @Prop(() => String, { required: true }) email!: string;
  @Prop(() => String, { nullable: true }) phone!: string | null;
  @Prop(() => Number) age?: number;
  @Prop(() => [Card]) cards!: Card[];
  @Prop(() => Spec.map(String)) notes?: Map<string, string>;
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
const Customers = client.db().model(Customer);
// ---cut---
const rows = await Customers.find().sort({ name: 1 }).plain().mask({ name: (name) => `${name[0]}…` });
console.log(rows.map((row) => row.name));
// → ["A…", "B…"]
```

Если функция бросила ошибку, запрос падает с `QueryError: mask: the mask of "email" (model Customer) threw`. Молча отдать настоящее значение вместо маски значило бы допустить утечку, поэтому ошибка всегда громкая.

## Замаскировать документ

У загруженного документа есть три способа превратиться в данные — [`$toPlain`](../reference/documents/document-api.mdx#toplain), [`$toObject`](../reference/documents/document-api.mdx#toobject) и [`$toJSON`](../reference/documents/document-api.mdx#tojson). Их опция `mask` принимает тот же объект «путь → маска» и работает на копии. Сам документ и его следующее сохранение не меняются. Пути называют поля той формы, в которую сериализуется документ.

```ts twoslash
import { Entity, Mask, Prop, Schema, Spec, TypemoClient } from "@venloc/typemo";
@Schema()
class Card { @Prop(() => String, { required: true }) number!: string; @Prop(() => String) holder?: string; }
@Schema({ collection: "customers" })
class Customer extends Entity {
  @Prop(() => String, { required: true }) name!: string;
  @Prop(() => String, { required: true }) email!: string;
  @Prop(() => String, { nullable: true }) phone!: string | null;
  @Prop(() => Number) age?: number;
  @Prop(() => [Card]) cards!: Card[];
  @Prop(() => Spec.map(String)) notes?: Map<string, string>;
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
const Customers = client.db().model(Customer);
// ---cut---
const alice = await Customers.findOne({ name: "Alice" }).orFail();

const json = alice.$toJSON({ mask: { "cards.number": Mask.card() } });
console.log(json.cards.map((card) => card.number), alice.email);
// → ["************4242", "************4444"] "alice@gmail.com"
```

Документ остался нетронутым, `alice.email` по-прежнему настоящая почта. Так можно отдать клиенту замаскированную копию и дальше работать с настоящими данными.

## Замаскировать результат агрегации

Агрегация тоже возвращает данные, которые уходят наружу. У неё есть свой [`.mask`](../reference/aggregation/pipeline.mdx) с теми же правилами, и вызывать его тоже нужно после `.plain()` или `.lean()`.

```ts twoslash
import { Entity, Mask, Prop, Schema, Spec, TypemoClient } from "@venloc/typemo";
@Schema()
class Card { @Prop(() => String, { required: true }) number!: string; @Prop(() => String) holder?: string; }
@Schema({ collection: "customers" })
class Customer extends Entity {
  @Prop(() => String, { required: true }) name!: string;
  @Prop(() => String, { required: true }) email!: string;
  @Prop(() => String, { nullable: true }) phone!: string | null;
  @Prop(() => Number) age?: number;
  @Prop(() => [Card]) cards!: Card[];
  @Prop(() => Spec.map(String)) notes?: Map<string, string>;
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
const Customers = client.db().model(Customer);
// ---cut---
const rows = await Customers.aggregate((p) => p.match({ name: "Alice" }))
  .plain()
  .mask({ email: Mask.email() });
console.log(rows.map((row) => row.email));
// → ["a***@gmail.com"]
```

## Читать большими выборками

У запроса с маской есть [`.cursor()`](../reference/query/cursor.mdx). Маска применяется к каждой строке по ходу чтения, и память не растёт вместе с выборкой.

```ts twoslash
import { Entity, Mask, Prop, Schema, Spec, TypemoClient } from "@venloc/typemo";
@Schema()
class Card { @Prop(() => String, { required: true }) number!: string; @Prop(() => String) holder?: string; }
@Schema({ collection: "customers" })
class Customer extends Entity {
  @Prop(() => String, { required: true }) name!: string;
  @Prop(() => String, { required: true }) email!: string;
  @Prop(() => String, { nullable: true }) phone!: string | null;
  @Prop(() => Number) age?: number;
  @Prop(() => [Card]) cards!: Card[];
  @Prop(() => Spec.map(String)) notes?: Map<string, string>;
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
const Customers = client.db().model(Customer);
// ---cut---
const cursor = Customers.find().sort({ name: 1 }).plain().mask({ email: Mask.email() }).cursor();
for await (const row of cursor) console.log(row.email);
// → "a***@gmail.com"
// → "b***@example.org"
```

## Как выбрать

Спросите себя, **нужно ли клиенту видеть это поле хоть в каком-то виде**.

- **Нет** — не читайте его. Исключение через `.select` или `hidden` в модели надёжнее любой маски, значение просто не покидает базу.
- **Нужно в узнаваемой, но неполной форме**, вроде последних цифр карты, домена почты или диапазона возраста, — берите `.mask` в запросе.
- **Поле должно быть замаскировано везде**, включая журналы, события и тексты ошибок, — задайте `sensitive` в модели. Маски те же `Mask.*`, только действуют постоянно, а не в одном запросе. Подробности в руководстве [Скрытые и чувствительные поля](../schemas/hidden-and-sensitive.mdx).

## Когда это не нужно

Сама по себе маска не защищает. Она прячет значение только в том результате, к которому применена. Если поле не должно покидать базу, берите `.select` или `hidden`.

Если данные отдаются с разным уровнем доступа, решайте это на уровне запросов и моделей, а не масками в каждом обработчике. Одна забытая маска — и значение ушло целиком. Проверка путей у `.mask` ловит опечатки, но не забытые вызовы.

## Если что-то пошло не так

**`.mask` не компилируется на документе.** Вы вызвали `.mask` у запроса без `.plain()` или `.lean()`. Документ с замаскированными значениями можно случайно сохранить, и в базу ляжет маска вместо данных. Поэтому Typemo это запрещает, и маска работает только на обычных объектах. В коде без типов вызов бросает `QueryError` с тем же текстом, что показывает компилятор.

```ts twoslash
import { Entity, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema({ collection: "customers" })
class Customer extends Entity {
  @Prop(() => String, { required: true }) name!: string;
  @Prop(() => String, { required: true }) email!: string;
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
const Customers = client.db().model(Customer);
// ---cut---
// неправильно: у документа нет масок
// @errors: 2684
await Customers.find().mask({ email: "mask" });
// компилятор: … 'PathError<"mask() masks rows: call .lean() or .plain() first — a hydrated document with masked values could be saved">'

// правильно: маска у обычных объектов
await Customers.find().plain().mask({ email: "mask" });
```

**Компилятор не принимает путь.** Путь, которого нет в строке результата, не скомпилируется, так что опечатку в имени поля маска не пропустит.

```ts twoslash
import { Entity, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema({ collection: "customers" })
class Customer extends Entity {
  @Prop(() => String, { required: true }) name!: string;
  @Prop(() => String, { required: true }) email!: string;
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
const Customers = client.db().model(Customer);
// ---cut---
// @errors: 2322
await Customers.find().plain().mask({ emial: "mask" });
// компилятор: Type '"mask"' is not assignable to type '"mask" & PathError<"mask: \"emial\" is not a path of the result row">'
```

Если объект масок собран из данных, которых компилятор не видит, путь проверяет сам Typemo. Несуществующий путь ничего бы не замаскировал, и значение ушло бы настоящим. Поэтому `.mask` бросает `StrictModeError` сразу при вызове, ещё до запроса к базе.

```text
StrictModeError: mask: "emial" is not a path of Customer's rows, so it would mask nothing; name a field of the rows [unknown-path]
```

Но осторожность проверка не заменит. Не делайте маску единственной защитой.

**Готовая маска не подходит к типу поля.** Маска типизирована значением, которое принимает. `Mask.email()` принимает строку, поэтому для числового поля она не скомпилируется.

```ts twoslash
import { Entity, Mask, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema({ collection: "customers" })
class Customer extends Entity {
  @Prop(() => String, { required: true }) name!: string;
  @Prop(() => Number) age?: number;
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
const Customers = client.db().model(Customer);
// ---cut---
// неправильно: почтовая маска на числе
// @errors: 2322
await Customers.find().plain().mask({ age: Mask.email() });

// правильно: маска для чисел
await Customers.find().plain().mask({ age: Mask.bucket([18, 35, 60]) });
```

**Маска показала `"?"` вместо значения.** Готовая маска не бросает ошибок из-за данных. Значение не того вида, например почту без `@` или слишком короткий номер, она заменяет на `"?"`. Потерять деталь лучше, чем раскрыть значение. Если вы видите `"?"` там, где ждали частичное значение, проверьте само значение в базе.

## Полный пример

Здесь всё вместе — запрос для поддержки с масками, вложенные значения и маска документа. Код, которого нет в Typemo и который пишете вы, помечен `__…__`.

```ts twoslash title="customers/support.service.ts"
import { Entity, Mask, Prop, Schema, Spec, TypemoClient } from "@venloc/typemo";

@Schema()
class Card {
  @Prop(() => String, { required: true })
  number!: string;

  @Prop(() => String)
  holder?: string;
}

@Schema({ collection: "customers" })
class Customer extends Entity {
  @Prop(() => String, { required: true })
  name!: string;

  @Prop(() => String, { required: true })
  email!: string;

  @Prop(() => String, { nullable: true })
  phone!: string | null;

  @Prop(() => Number)
  age?: number;

  @Prop(() => [Card])
  cards!: Card[];

  @Prop(() => Spec.map(String))
  notes?: Map<string, string>;
}

// код читателя: ошибка на границе приложения
class __NotFound__ extends Error {}

export const createSupportService = (client: TypemoClient) => {
  const Customers = client.db().model(Customer);

  // список: контакты и возраст показываются частично
  const list = () =>
    Customers.find()
      .sort({ name: 1 })
      .plain()
      .mask({ email: Mask.email(), phone: Mask.phone(), age: Mask.bucket([18, 35, 60]) });

  // карточка клиента: номера карт скрыты, заметки закрыты целиком
  const card = async (name: string) => {
    const [customer] = await Customers.find({ name })
      .plain()
      .mask({ "cards.number": Mask.card(), "notes.$*": "mask" });
    if (customer === undefined) throw new __NotFound__(`customer ${name} is missing`);
    return customer;
  };

  // документ уже загружен: копия для ответа с маской, оригинал не тронут
  const forResponse = async (name: string) => {
    const customer = await Customers.findOne({ name }).orFail();
    return customer.$toJSON({ mask: { email: Mask.email(), "cards.number": Mask.card() } });
  };

  return { list, card, forResponse };
};
```

В Mongoose масок ответа нет. Значения прятали в геттерах схемы или вручную перед отправкой. В Typemo это отдельный шаг запроса. [`.mask`](../reference/query/masks.mdx#mask) применяется после чтения к копии, документ не меняется, тип результата учитывает маски, а путь и тип маски проверяет компилятор.

</Callout>
