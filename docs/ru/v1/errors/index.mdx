В этом разделе собрана задача, с которой сталкивается каждое приложение: превратить отказ библиотеки или базы в понятное действие или ответ клиенту. Typemo бросает ошибки, а не молча исправляет ввод, поэтому граница приложения должна их обработать. Полное описание каждого класса лежит в [справочнике раздела](../reference/errors/index.mdx).
