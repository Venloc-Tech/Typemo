Словарь (**Map**) нужен, когда набор ключей заранее неизвестен: цена товара в каждой валюте, оценки по предметам, настройки по названиям. В схеме его объявляет [`Spec.map`](../reference/schemas/types-and-spec.mdx#specmap): ключи всегда строки, а тип значений вы задаёте сами. В базе словарь хранится как обычный вложенный документ (`{ USD: 10, EUR: 9 }`), а в коде загруженного документа это `Map<string, V>`.

Главное отличие от вложенного объекта в том, что ключи словаря — это данные, а не имена полей схемы. Поэтому Typemo проверяет сами ключи: MongoDB читает точку в имени как путь, а `$` в начале как оператор, и такой ключ позже невозможно ни найти, ни обновить. Библиотека отвергает их сразу.

## Что предполагается

Модель описана по руководству [Описать модель](./define-model.mdx). Примеры строят карточку товара с ценами по валютам.

## Быстрый путь

```ts twoslash title="shop/product.ts"
import { Entity, Prop, Schema, Spec, TypemoClient, Types, Virtual, type Computed, type Defaulted, type Hidden, type Immutable, type Ref, type VirtualRef } from "@venloc/typemo";
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
// ---cut---
@Schema({ collection: "products" })
export class Product extends Entity {
  @Prop(() => String, { required: true })
  title!: string;

  @Prop(() => Spec.map(Number))
  prices?: Map<string, number>;
}

const Products = client.connection.model(Product);
const product = await Products.create({ title: "Lamp", prices: { USD: 10, EUR: 9 } });
product.prices?.set("GBP", 8);
console.log([...(product.prices ?? [])]);
// → [["USD", 10], ["EUR", 9], ["GBP", 8]]
```

Значение передаётся обычным объектом (или `Map`), а в загруженном документе поле — строго типизированная карта, у которой есть `set`, `delete` и `clear`. Остальная страница разбирает ключи, значения и поиск.

## Разрешённые ключи

Ключ — непустая строка без точки, без `$` в начале и не `__proto__`. Причины конкретные: пустой ключ нельзя записать в путь, точка превратилась бы во вложенный путь, `$` в начале MongoDB приняла бы за оператор, а `__proto__` в JavaScript меняет прототип объекта и открывает дорогу к подмене свойств.

```ts twoslash
import { Entity, Prop, Schema, Spec, TypemoClient, Types, Virtual, type Computed, type Defaulted, type Hidden, type Immutable, type Ref, type VirtualRef } from "@venloc/typemo";
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
@Schema({ collection: "products" })
class Product extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => Spec.map(Number)) prices?: Map<string, number>;
}
const Products = client.connection.model(Product);
// ---cut---
try {
  await Products.create({ title: "Lamp", prices: { "a.b": 1 } });
} catch (error) {
  console.log((error as Error).message);
}
// → Cast to Map key failed at path "prices.a.b" for "a.b" (string): a key cannot contain "." (it would be read as a path) [key]
try {
  await Products.create({ title: "Lamp", prices: { $x: 1 } });
} catch (error) {
  console.log((error as Error).message);
}
// → Cast to Map key failed at path "prices.$x" for "$x" (string): a key cannot start with "$" (reserved for operators) [key]
try {
  await Products.create({ title: "Lamp", prices: { "": 1 } });
} catch (error) {
  console.log((error as Error).message);
}
// → Cast to Map key failed at path "prices" for "" (string): an empty key cannot be addressed by a path [key]
```

Если ключи приходят от пользователя, например название настройки, проверяйте или нормализуйте их до записи: ключ с точкой не пройдёт, и лучше знать об этом раньше, чем `create` вернёт ошибку клиенту.

## Проверить значения

Значения приводятся к типу, заданному в `Spec.map`, и ошибка называет ключ в пути. `null` в значении запрещён, пока вы не разрешите его явно опцией `nullable`: `Spec.map(Number, { nullable: true })` даёт `Map<string, number | null>`.

```ts twoslash
import { Entity, Prop, Schema, Spec, TypemoClient, Types, Virtual, type Computed, type Defaulted, type Hidden, type Immutable, type Ref, type VirtualRef } from "@venloc/typemo";
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
@Schema({ collection: "products" })
class Product extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => Spec.map(Number)) prices?: Map<string, number>;
}
const Products = client.connection.model(Product);
// ---cut---
try {
  await Products.create({ title: "Lamp", prices: { USD: "x" as never } });
} catch (error) {
  console.log((error as Error).message);
}
// → Cast to number failed at path "prices.USD" for "x" (string): expected a number [type]
```

Значением может быть и класс со схемой: `Spec.map(Line)` хранит словарь поддокументов. Все правила поддокумента (обязательные поля, `min`) применяются к каждому значению.

## Искать и обновлять по ключу

Ключ словаря работает как путь: `"prices.EUR"` в фильтре находит товары с ценой в евро, а в `$set` меняет одно значение и не затрагивает остальные. Типы значения проверяются так же, как в самом поле.

```ts twoslash
import { Entity, Prop, Schema, Spec, TypemoClient, Types, Virtual, type Computed, type Defaulted, type Hidden, type Immutable, type Ref, type VirtualRef } from "@venloc/typemo";
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
@Schema({ collection: "products" })
class Product extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => Spec.map(Number)) prices?: Map<string, number>;
}
const Products = client.connection.model(Product);
await Products.create({ title: "Lamp", prices: { USD: 10 } });
// ---cut---
await Products.updateOne({ title: "Lamp" }, { $set: { "prices.EUR": 9 } });
const found = await Products.find({ "prices.EUR": 9 }).plain();
console.log(found.length);
// → 1
```

## Прочитать словарь в разных видах

Загруженный документ отдаёт `Map` с проверкой ключей и значений. [`.plain()`](../reference/query/reading.mdx#plain) и [`$toPlain()`](../reference/documents/document-api.mdx#toplain) сохраняют `Map`, [`$toJSON()`](../reference/documents/document-api.mdx#tojson) превращает его в обычный объект, потому что JSON не знает `Map`, а [`.lean()`](../reference/query/reading.mdx#lean) отдаёт то, что лежит в базе, то есть обычный объект.

```ts twoslash
import { Entity, Prop, Schema, Spec, TypemoClient, Types, Virtual, type Computed, type Defaulted, type Hidden, type Immutable, type Ref, type VirtualRef } from "@venloc/typemo";
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
@Schema({ collection: "products" })
class Product extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => Spec.map(Number)) prices?: Map<string, number>;
}
const Products = client.connection.model(Product);
await Products.create({ title: "Lamp", prices: { USD: 10, EUR: 9 } });
// ---cut---
const plain = await Products.findOne({ title: "Lamp" }).plain();
console.log(plain?.prices instanceof Map);
// → true
const doc = await Products.findOne({ title: "Lamp" }).orFail();
console.log(doc.$toJSON().prices);
// → { USD: 10, EUR: 9 }
const lean = await Products.findOne({ title: "Lamp" }).lean();
console.log(lean?.prices instanceof Map);
// → false
```

## Как выбрать

Задайте себе один вопрос: **известны ли все ключи заранее?** Если да (город и улица, имя и фамилия), опишите вложенный объект: поля видны в подсказках и проверяются по отдельности, см. [Вложенные объекты и поддокументы](./nested-and-subdocuments.mdx). Если нет и ключи приходят как данные (валюты, языки, названия настроек), берите `Spec.map`. Если вам нужен список пар, где ключи могут повторяться, это [массив](./arrays.mdx) поддокументов с полями `key` и `value`.

## Когда это не нужно

Индексировать значения словаря по ключу заранее нельзя: набор путей неизвестен, поэтому для быстрого поиска по значению лучше хранить пары массивом поддокументов и строить индекс по их полям. Тип поля `Map` из JavaScript напрямую не подходит: `@Prop(() => Map)` не поддерживается, для него предназначен `Spec.map`.

## Частые ошибки

### Ключ с точкой в названии

Данные вроде `{ "v1.2": 5 }` не записываются: `a key cannot contain "."`. Причина в том, что MongoDB читает точку как путь, и поле нельзя было бы найти. Замените точку в ключе на другой символ.

### `null` в значении

`Spec.map(Number)` не принимает `null`: `Cast to number failed at path "prices.a" for null: null is not allowed on a path that is not nullable [null]`. Разрешите его явно опцией `nullable: true` или не передавайте ключ.

## Полный пример

Один файл собирает товар с ценами по валютам, запись и чтение. Код читателя, которого нет в Typemo, помечен `__…__`.

```ts twoslash title="shop/products.service.ts"
import { Entity, Prop, Schema, Spec, TypemoClient, Types, Virtual, type Computed, type Defaulted, type Hidden, type Immutable, type Ref, type VirtualRef } from "@venloc/typemo";
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
// ---cut---
// модель: цены по валютам в словаре
@Schema({ collection: "products" })
class Product extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => Spec.map(Number)) prices?: Map<string, number>;
}

// код читателя: ошибка на границе приложения
class __BadRequest__ extends Error {}

// создание товара: ключи проверяются при записи
export const addProduct = async (title: string, prices: Record<string, number>) => {
  const Products = client.connection.model(Product);
  try {
    return await Products.create({ title, prices });
  } catch (error) {
    throw new __BadRequest__((error as Error).message);
  }
};

// смена одной цены: путь по ключу, остальные не затрагиваются
export const setEuroPrice = async (title: string, price: number) => {
  const Products = client.connection.model(Product);
  await Products.updateOne({ title }, { $set: { "prices.EUR": price } });
};

await addProduct("Lamp", { USD: 10 });
await setEuroPrice("Lamp", 9);
const lamp = await client.connection.model(Product).findOne({ title: "Lamp" }).orFail();
console.log(lamp.$toJSON().prices);
// → { USD: 10, EUR: 9 }
```

<Callout type="migration">

В Mongoose поле-словарь описывают как `type: Map, of: Number`. В Typemo это `Spec.map(Number)`, а `Map` как тип поля не поддерживается. Запрещённые ключи (`__proto__`, с `.`, с `$` в начале, пустой) отвергаются при записи.

</Callout>
