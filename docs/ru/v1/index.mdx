**Typemo** — ODM для MongoDB на TypeScript, написанный с нуля: вы описываете схему классом с декораторами, а типы моделей, запросов и результатов выводятся из этого класса, а не приклеены поверх чужого рантайма. Строгость по умолчанию абсолютна: неизвестное поле, `undefined` в фильтре или пустой фильтр в записи — это ошибка, а не тихое поведение, и ослабить это нельзя ни опцией, ни режимом. Транспорт — официальный драйвер `mongodb`, а Typemo строится только на последних версиях MongoDB, драйвера, `bson`, Bun и TypeScript.

## Как это выглядит

Класс описывает счёт один раз. Дальше компилятор знает, какие поля есть у модели, какие из них можно выбрать и какой тип получит результат: здесь после `select` и `plain` тип содержит только `_id` и `title`, причём `_id` уже строка, которую можно отдать клиенту.

```ts twoslash
import { Entity, Prop, Schema, TypemoClient } from "@venloc/typemo";

@Schema({ collection: "accounts" })
class Account extends Entity {
  @Prop(() => String, { required: true })
  title!: string;

  @Prop(() => Number, { required: true, min: 0 })
  balance!: number;
}

const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "bank" });
const Accounts = client.db().model(Account);
// ---cut---
const rows = await Accounts.find({ balance: { $gt: 100 } }).select({ title: 1 }).plain();
//    ^?
```

Опечатка в имени поля не даёт скомпилироваться, а если типы обойдены, запрос упадёт до обращения к базе. Как это устроено, объясняет концепция [Что такое Typemo](./concepts/what-is-typemo.mdx).

## Поддерживаемые версии

Typemo проверяется на MongoDB `8.3` и `9.0.0-rc0`, драйвере `mongodb` `7.6.0`, `bson` `7.3.3`, Bun `1.4.0` и TypeScript `6.0.3`. Старые версии не поддерживаются, а на Node.js проверен только дымовой сценарий собранного пакета. Полный список и всё непроверенное — в [Совместимости версий](./appendix/versions.mdx).
