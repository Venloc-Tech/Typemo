Индекс по одному полю задаётся опцией поля ([`index`](./prop.mdx#index), [`unique`](./prop.mdx#unique), [`expires`](./prop.mdx#expires), [`text`](./prop.mdx#text)). Всё остальное описывается декораторами класса: `@Index` для обычных индексов MongoDB — составных, частичных, с временем жизни, текстовых, wildcard, — а `@SearchIndex` для индексов Atlas Search и векторного поиска. Сюда приходят, чтобы уточнить опции и правила проверки.

Руководство с задачами — [Индексы](../../schemas/indexes.mdx). Эта страница — справочник.

Примеры используют модель заметки: владелец, дата, почта, признак активности, заголовок и текст. Результаты `// →` получены запуском на настоящей MongoDB.

## @Index

`@Index(поля, опции?)` объявляет индекс класса. Первый аргумент — объект `{ путь: направление }` в порядке ключей индекса. Направление — `1` (по возрастанию), `-1` (по убыванию), `"hashed"`, `"text"`, `"2dsphere"` или `"2d"`. Пути, включая пути в `partialFilterExpression`, `weights` и `wildcardProjection`, компилятор сверяет с классом: опечатка — ошибка на этапе компиляции, явный тип `<Note>` не нужен. Декоратор повторяемый: каждое применение добавляет ещё один индекс. Одинаковые индексы объединяются, а два индекса с одним именем или ключами и разными опциями — `ConfigurationError` (`two indexes named or keyed "by_owner" with different definitions`).

```ts twoslash
import { Discriminator, Entity, Index, Prop, Schema, SearchIndex, Spec, Timestamped, TypemoClient, Types, Versioned, Virtual, type Computed, type Defaulted, type DiscriminatorValue, type Hidden, type Immutable, type Ref, type SpecValue, type TenantField, type VirtualRef, type VirtualValue, type Unbranded, type Int64String, type Vector } from "@venloc/typemo";
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
// ---cut---
@Index({ owner: 1, createdAt: -1 }, { name: "by_owner" }) // [!code highlight]
@Schema()
class Note extends Entity {
  @Prop(() => String) owner?: string;
  @Prop(() => Date) createdAt?: Date;
}
const Notes = client.db().model(Note);
console.log(Notes.schema.describe().indexes);
// → [{ keys: { owner: 1, createdAt: -1 }, options: { name: "by_owner" } }]
```

Опечатка в имени поля останавливает компиляцию, и сообщение называет путь:

```ts twoslash
import { Discriminator, Entity, Index, Prop, Schema, SearchIndex, Spec, Timestamped, TypemoClient, Types, Versioned, Virtual, type Computed, type Defaulted, type DiscriminatorValue, type Hidden, type Immutable, type Ref, type SpecValue, type TenantField, type VirtualRef, type VirtualValue, type Unbranded, type Int64String, type Vector } from "@venloc/typemo";
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
// ---cut---
// @errors: 1238
@Index({ ownr: 1 })
@Schema()
class Note extends Entity {
  @Prop(() => String) owner?: string;
}
```

Внутри сообщения: `@Index: "ownr" is not a field of the class`. Индексы создаются при [`connection.init()`](../connection/connection.mdx#connectioninit) и [`connection.syncAll()`](../connection/connection.mdx#connectionsyncall) (если не выключена опция [`autoIndex`](./schema.mdx#autoindex)); сама модель их не строит; созданные индексы совпали с объявленными: сервер показал `by_owner`, `email_active`, `ttl` и остальные с теми же ключами и опциями.

## name

`name` — имя индекса. Без него имя выбирает сервер по ключам (`owner_1_createdAt_-1`). Своё имя нужно, когда на него ссылаются подсказка запроса или миграция.

## unique

`unique: true` не допускает два документа с одинаковым значением ключа. Значение записи-нарушителя — [`DuplicateKeyError`](../errors/server-errors.mdx#duplicatekeyerror). В отличие от `unique` поля, в `@Index` нет проверки на `required`: для необязательного поля используйте `partialFilterExpression`, чтобы документы без значения не попадали в индекс.

```ts twoslash
import { Discriminator, Entity, Index, Prop, Schema, SearchIndex, Spec, Timestamped, TypemoClient, Types, Versioned, Virtual, type Computed, type Defaulted, type DiscriminatorValue, type Hidden, type Immutable, type Ref, type SpecValue, type TenantField, type VirtualRef, type VirtualValue, type Unbranded, type Int64String, type Vector } from "@venloc/typemo";
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
// ---cut---
@Index({ email: 1 }, { unique: true, partialFilterExpression: { active: true }, name: "email_active" }) // [!code highlight]
@Schema()
class Account extends Entity {
  @Prop(() => String) email?: string;
  @Prop(() => Boolean) active?: boolean;
}
const Accounts = client.db().model(Account);
console.log(Accounts.schema.describe().indexes);
// → [{ keys: { email: 1 }, options: { unique: true, partialFilterExpression: { active: true }, name: "email_active" } }]
```

## sparse

`sparse: true` индексирует только документы, у которых есть поле. С `partialFilterExpression` сочетать нельзя: `ConfigurationError` (`@Index({"a":1}): "sparse" and "partialFilterExpression" cannot be combined (server rule)`). Для новых индексов лучше `partialFilterExpression`, он выражает то же и больше.

---

## partialFilterExpression

`partialFilterExpression` — фильтр, по которому в индекс попадают только подходящие документы: индекс меньше, а уникальность действует только среди них. Сервер принимает не любой фильтр: равенство, `$exists: true`, `$gt`, `$gte`, `$lt`, `$lte`, `$type`, `$in` и `$and`/`$or` на верхнем уровне. Тип `PartialFilter` в Typemo описывает именно этот набор. Пути проверяются по классу; неизвестный путь — ошибка компиляции (`@Index: partialFilterExpression "zz" is not a field of the class`) и сборки (`partialFilterExpression "zz" is not a field of the class`).

## expireAfterSeconds

`expireAfterSeconds` — время жизни документов в секундах после значения даты: индекс TTL, по которому MongoDB сама удаляет старые документы. Индекс должен быть **по одному полю типа `Date`**, иначе `ConfigurationError` (`@Index({"a":1}): expireAfterSeconds (TTL) needs a single-field index on a Date field`). Для TTL по одному полю проще опция поля [`expires`](./prop.mdx#expires).

```ts twoslash
import { Discriminator, Entity, Index, Prop, Schema, SearchIndex, Spec, Timestamped, TypemoClient, Types, Versioned, Virtual, type Computed, type Defaulted, type DiscriminatorValue, type Hidden, type Immutable, type Ref, type SpecValue, type TenantField, type VirtualRef, type VirtualValue, type Unbranded, type Int64String, type Vector } from "@venloc/typemo";
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
// ---cut---
@Index({ lastSeen: 1 }, { expireAfterSeconds: 60, name: "ttl" }) // [!code highlight]
@Schema()
class Session extends Entity {
  @Prop(() => Date) lastSeen?: Date;
}
const Sessions = client.db().model(Session);
console.log(Sessions.schema.describe().indexes);
// → [{ keys: { lastSeen: 1 }, options: { expireAfterSeconds: 60, name: "ttl" } }]
```

## collation

`collation` — правила сравнения строк для индекса: язык, регистр, акценты. Индекс без своих правил наследует правила коллекции ([`collation`](./schema.mdx#collation) схемы). Текстовые индексы и `2d` сортировку не поддерживают: при сортировке коллекции их нужно объявить с `collation: { locale: "simple" }`, иначе `ConfigurationError`.

## weights

`weights` — веса полей **текстового** индекса: чем больше вес, тем важнее совпадение в этом поле. Ключи — поля класса (`@Index: weights."x" is not a field of the class`). Текстовый индекс в коллекции один: поля с `text: true` и текстовый `@Index` вместе — `ConfigurationError`.

```ts twoslash
import { Discriminator, Entity, Index, Prop, Schema, SearchIndex, Spec, Timestamped, TypemoClient, Types, Versioned, Virtual, type Computed, type Defaulted, type DiscriminatorValue, type Hidden, type Immutable, type Ref, type SpecValue, type TenantField, type VirtualRef, type VirtualValue, type Unbranded, type Int64String, type Vector } from "@venloc/typemo";
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
// ---cut---
@Index({ title: "text", body: "text" }, { weights: { title: 5 }, default_language: "english", name: "search" }) // [!code highlight]
@Schema()
class Article extends Entity {
  @Prop(() => String) title?: string;
  @Prop(() => String) body?: string;
}
const Articles = client.db().model(Article);
console.log(Articles.schema.describe().indexes);
// → [{ keys: { title: "text", body: "text" }, options: { weights: { title: 5 }, default_language: "english", name: "search" } }]
```

Сервер построил индекс с весами `title: 5` и `body: 1`. Ключи текстового индекса он хранит в служебной форме (`_fts`, `_ftsx`), а вес по умолчанию записывает сам. Typemo учитывает это при сравнении: второй запуск [`connection.init()`](../connection/connection.mdx#connectioninit) на такой модели ничего не создаёт и не падает.

### default_language

Язык текстового индекса по умолчанию: правила основ слов и стоп-слова.

### language_override

Поле документа, значение которого переопределяет язык для этого документа.

## wildcardProjection

`wildcardProjection` — какие пути включать (`1`) или исключать (`0`) из wildcard-индекса `{ "$**": 1 }`. Ключи — поля класса.

```ts twoslash
import { Discriminator, Entity, Index, Prop, Schema, SearchIndex, Spec, Timestamped, TypemoClient, Types, Versioned, Virtual, type Computed, type Defaulted, type DiscriminatorValue, type Hidden, type Immutable, type Ref, type SpecValue, type TenantField, type VirtualRef, type VirtualValue, type Unbranded, type Int64String, type Vector } from "@venloc/typemo";
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
// ---cut---
@Index({ "$**": 1 }, { wildcardProjection: { title: 1 }, name: "wild" }) // [!code highlight]
@Schema()
class Article extends Entity {
  @Prop(() => String) title?: string;
}
const Articles = client.db().model(Article);
console.log(Articles.schema.describe().indexes);
// → [{ keys: { "$**": 1 }, options: { wildcardProjection: { title: 1 }, name: "wild" } }]
```

## hidden

`hidden: true` прячет индекс от планировщика запросов, не удаляя его: индекс продолжает обновляться. Так проверяют, что случится без индекса, прежде чем удалять его.

---

## @SearchIndex

`@SearchIndex({ name, type?, definition })` объявляет индекс Atlas Search или векторного поиска. Декоратор только записывает описание; индекс создаётся на сервере при синхронизации. Обычный `mongod` таких индексов не поддерживает: [`connection.init()`](../connection/connection.mdx#connectioninit) на нём бросает [`SyncError`](../errors/configuration-errors.mdx#syncerror), а в списке сбоев — ответ сервера `SearchNotEnabled` (код 31082) о том, что для команд Atlas Search нужна дополнительная настройка. Запуск на Atlas не проверялся.

```ts twoslash
import { Discriminator, Entity, Index, Prop, Schema, SearchIndex, Spec, Timestamped, TypemoClient, Types, Versioned, Virtual, type Computed, type Defaulted, type DiscriminatorValue, type Hidden, type Immutable, type Ref, type SpecValue, type TenantField, type VirtualRef, type VirtualValue, type Unbranded, type Int64String, type Vector } from "@venloc/typemo";
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "app" });
// ---cut---
@SearchIndex({ name: "default", definition: { mappings: { dynamic: true } } }) // [!code highlight]
@Schema()
class Article extends Entity {
  @Prop(() => String) title?: string;
}
```

<Params>
<Param name="options.name" type="string" required>

Имя индекса.

</Param>
<Param name="options.type" type="&quot;search&quot; | &quot;vectorSearch&quot;" default="&quot;search&quot;">

Вид индекса: полнотекстовый или векторный.

</Param>
<Param name="options.definition" type="Record<string, unknown>" required>

Описание индекса в том виде, в котором его ждёт Atlas API. Typemo содержимое не проверяет.

</Param>
</Params>

В описании схемы ([`describe()`](./schema-info.mdx#describe)) поисковые индексы лежат в отдельном поле `searchIndexes`, а не в `indexes`: там имя и определение в порядке объявления.

## Когда не подходит

Индекс по одному полю проще объявить опцией поля ([`index`](./prop.mdx#index), [`unique`](./prop.mdx#unique)). Уникальность вместе с необязательным полем на поле без `sparse` Typemo запрещает, и `@Index` с `partialFilterExpression` — способ обойти это правильно. Настройки коллекции целиком — в [`@Schema`](./schema.mdx#schema).
