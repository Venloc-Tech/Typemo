Справочник описывает каждый элемент публичного API полностью. Что он принимает, что возвращает, какие ошибки бросает и когда не подходит — всё здесь. Разделы повторяют руководства. Руководству `queries/…` соответствует справочник `reference/query/…`. Решаете задачу и не знаете, с чего начать? Откройте руководства из [«Начала работы»](../getting-started/index.mdx). Они ведут от задачи к решению и отсылают сюда за подробностями.

Каждая страница справочника начинается с обзора, а элементы на ней описаны одним шаблоном. Прочитав одну страницу, вы знаете, где искать нужное на любой другой. Незнакомое слово найдёте в [глоссарии](../appendix/glossary.mdx).
