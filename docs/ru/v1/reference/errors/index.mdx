Справочник описывает каждый класс ошибки полностью. Для каждого есть ситуации, в которых он бросается, его поля, способ поймать его и ответ клиенту. Если вам нужно понять, как обрабатывать ошибки в приложении, начните с [руководства раздела](../../errors/index.mdx). Оно ведёт от задачи к решению и отсылает сюда за подробностями.

<Cards>
<Card title="Иерархия ошибок" href="./hierarchy.mdx">
  Дерево классов, общие поля `TypemoError`, `PostHookError` (хук упал после записи) и `ErrorClassifier` (разбор любой ошибки для повторов и метрик).
</Card>
<Card title="Ошибки данных" href="./data-errors.mdx">
  `ValidationError`, `CastError`, `StrictModeError`, `UnknownFieldsError`, `DirectWriteError` и `PartialArrayError`.
</Card>
<Card title="Ошибки запросов" href="./query-errors.mdx">
  `QueryError`, `DocumentNotFoundError`, `VersionError`, `KeysetTokenError` и `EachAsyncError`.
</Card>
<Card title="Ошибки сервера" href="./server-errors.mdx">
  `ServerError` (с полями `serverMessage` и `codeName`), `DuplicateKeyError`, `ServerValidationError`, `WriteConflictError`, `TimeoutError`, `BulkWriteError`, `ServerErrorCodes` и `ErrorLabels`.
</Card>
<Card title="Ошибки конфигурации и подключения" href="./configuration-errors.mdx">
  `ConfigurationError`, `ConnectionError`, `DriverError`, `IndexSyncError`, `SyncError` (итог неудавшегося `init()` и `syncAll()`), `CollectionOptionsError`, `AuditError` и `InternalError`.
</Card>
</Cards>
