На этой странице собраны операторы каталога `fn` для работы с датами: части даты, сложение и разность, округление, сборка, разбор и форматирование. Значения вычисляет сервер для каждой строки внутри стадии, например [`project`](./stages.mdx#project). Без `timezone` всё считается в UTC. Пояс можно задать названием (`"Asia/Tokyo"`) или смещением.

Если вы только начинаете, сначала прочитайте руководство [Выражения](../../aggregation/expressions.mdx). Эта страница — справочник. Выражения пишутся только колбэком: сырой объект с `$expr` Typemo не принимает.

Все примеры используют одну модель заказа магазина.

```ts twoslash title="models/order.ts"
import { Timestamp } from "mongodb";
import { Entity, Prop, Schema } from "@venloc/typemo";

@Schema()
export class Line {
  @Prop(() => String, { required: true })
  sku!: string;

  @Prop(() => Number, { required: true })
  qty!: number;
}

@Schema({ collection: "orders" })
export class Order extends Entity {
  @Prop(() => String, { required: true })
  title!: string;

  @Prop(() => String, { required: true })
  sku!: string;

  @Prop(() => Number, { required: true })
  price!: number;

  @Prop(() => Number, { required: true })
  quantity!: number;

  @Prop(() => Number, { required: true })
  delta!: number;

  @Prop(() => Number, { required: true })
  ratio!: number;

  @Prop(() => Number)
  discount?: number;

  @Prop(() => Date, { required: true })
  placedAt!: Date;

  @Prop(() => Date, { required: true })
  shippedAt!: Date;

  @Prop(() => Timestamp)
  stamp?: Timestamp;

  @Prop(() => [String])
  tags!: string[];

  @Prop(() => [Number])
  prices!: number[];

  @Prop(() => [Line])
  lines!: Line[];
}
```

В коллекции один заказ: `title` — `"  Blue Pen  "` (с пробелами по краям), `sku` — `"PEN-001"`, `price` — 19.99, `quantity` — 3, `delta` — -5, `ratio` — 0.5, `placedAt` — 15 марта 2026, 10:30:45.123 UTC, `shippedAt` — 18 марта 2026, 08:00 UTC, `stamp` — временная метка с секундами 1700000000 и приращением 5, `tags` — `["new", "sale", "pen"]`, `prices` — `[30, 10, 20]`, `lines` — две строки (`pen`×2 и `ink`×1). Поля `discount` у заказа нет. Результаты в комментариях `// →` получены запуском на этих данных.

## Части даты

Оператор принимает дату или объект `{ date, timezone }`. Без `timezone` части считаются в UTC. Для `null` и отсутствующего поля результат `null`.

Один запрос считает сразу все операторы группы:

```ts twoslash
import { Timestamp } from "mongodb";
import { Entity, fn, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema()
class Line {
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) qty!: number;
}
@Schema({ collection: "orders" })
class Order extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) price!: number;
  @Prop(() => Number, { required: true }) quantity!: number;
  @Prop(() => Number, { required: true }) delta!: number;
  @Prop(() => Number, { required: true }) ratio!: number;
  @Prop(() => Number) discount?: number;
  @Prop(() => Date, { required: true }) placedAt!: Date;
  @Prop(() => Date, { required: true }) shippedAt!: Date;
  @Prop(() => Timestamp) stamp?: Timestamp;
  @Prop(() => [String]) tags!: string[];
  @Prop(() => [Number]) prices!: number[];
  @Prop(() => [Line]) lines!: Line[];
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
const Orders = client.db().model(Order);
// ---cut---
const [row] = await Orders.aggregate((p) =>
  p.project((f) => ({
    year: fn.year(f.placedAt),
    month: fn.month(f.placedAt),
    dayOfMonth: fn.dayOfMonth(f.placedAt),
    hour: fn.hour(f.placedAt),
    minute: fn.minute(f.placedAt),
    second: fn.second(f.placedAt),
    millisecond: fn.millisecond(f.placedAt),
    dayOfWeek: fn.dayOfWeek(f.placedAt),
    dayOfYear: fn.dayOfYear(f.placedAt),
    week: fn.week(f.placedAt),
    isoWeek: fn.isoWeek(f.placedAt),
    isoWeekYear: fn.isoWeekYear(f.placedAt),
    isoDayOfWeek: fn.isoDayOfWeek(f.placedAt),
    _id: 0,
  })),
);
console.log(row);
// → {year: 2026, month: 3, dayOfMonth: 15, hour: 10, minute: 30, second: 45, millisecond: 123, dayOfWeek: 1, dayOfYear: 74, week: 11, isoWeek: 11, isoWeekYear: 2026n, isoDayOfWeek: 7}
```

Ниже каждый оператор описан отдельно.

### fn.year

Год. `fn.year(date)`.

Пример: `fn.year(f.placedAt)` даёт `2026`.

### fn.month

Месяц, 1–12. `fn.month(date)`.

Пример: `fn.month(f.placedAt)` даёт `3`.

### fn.dayOfMonth

День месяца. `fn.dayOfMonth(date)`.

Пример: `fn.dayOfMonth(f.placedAt)` даёт `15`.

### fn.hour

Час, 0–23. `fn.hour(date)`.

Пример: `fn.hour(f.placedAt)` даёт `10`.

### fn.minute

Минута. `fn.minute(date)`.

Пример: `fn.minute(f.placedAt)` даёт `30`.

### fn.second

Секунда. `fn.second(date)`.

Пример: `fn.second(f.placedAt)` даёт `45`.

### fn.millisecond

Миллисекунда. `fn.millisecond(date)`.

Пример: `fn.millisecond(f.placedAt)` даёт `123`.

### fn.dayOfWeek

День недели, воскресенье — 1. `fn.dayOfWeek(date)`.

Пример: `fn.dayOfWeek(f.placedAt)` даёт `1`.

### fn.dayOfYear

День года, 1–366. `fn.dayOfYear(date)`.

Пример: `fn.dayOfYear(f.placedAt)` даёт `74`.

### fn.week

Неделя года, 0–53, неделя начинается с воскресенья. `fn.week(date)`.

Пример: `fn.week(f.placedAt)` даёт `11`.

### fn.isoWeek

Неделя года по ISO 8601, 1–53. `fn.isoWeek(date)`.

Пример: `fn.isoWeek(f.placedAt)` даёт `11`.

### fn.isoWeekYear

Год по ISO-неделям; на сервере это int64, поэтому в типе `bigint`. `fn.isoWeekYear(date)`.

Пример: `fn.isoWeekYear(f.placedAt)` даёт `2026n`.

### fn.isoDayOfWeek

День недели по ISO, понедельник — 1. `fn.isoDayOfWeek(date)`.

Пример: `fn.isoDayOfWeek(f.placedAt)` даёт `7`.

## Арифметика дат

Все операторы принимают объект. Единица `unit` — одно из `year`, `quarter`, `week`, `month`, `day`, `hour`, `minute`, `second`, `millisecond`. С `timezone` границы дней и месяцев считаются в этом поясе, с учётом перехода на летнее время.

Один запрос считает сразу все операторы группы:

```ts twoslash
import { Timestamp } from "mongodb";
import { Entity, fn, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema()
class Line {
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) qty!: number;
}
@Schema({ collection: "orders" })
class Order extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) price!: number;
  @Prop(() => Number, { required: true }) quantity!: number;
  @Prop(() => Number, { required: true }) delta!: number;
  @Prop(() => Number, { required: true }) ratio!: number;
  @Prop(() => Number) discount?: number;
  @Prop(() => Date, { required: true }) placedAt!: Date;
  @Prop(() => Date, { required: true }) shippedAt!: Date;
  @Prop(() => Timestamp) stamp?: Timestamp;
  @Prop(() => [String]) tags!: string[];
  @Prop(() => [Number]) prices!: number[];
  @Prop(() => [Line]) lines!: Line[];
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
const Orders = client.db().model(Order);
// ---cut---
const [row] = await Orders.aggregate((p) =>
  p.project((f) => ({
    dateAdd: fn.dateAdd({ startDate: f.placedAt, unit: "day", amount: 7 }),
    dateSubtract: fn.dateSubtract({ startDate: f.placedAt, unit: "month", amount: 1 }),
    dateDiff: fn.dateDiff({ startDate: f.placedAt, endDate: f.shippedAt, unit: "day" }),
    dateTrunc: fn.dateTrunc({ date: f.placedAt, unit: "month" }),
    _id: 0,
  })),
);
console.log(row);
// → {dateAdd: new Date("2026-03-22T10: 30: 45.123Z"), dateSubtract: new Date("2026-02-15T10: 30: 45.123Z"), dateDiff: 3n, dateTrunc: new Date("2026-03-01T00: 00: 00.000Z")}
```

Ниже каждый оператор описан отдельно.

### fn.dateAdd

Прибавляет к дате `amount` единиц. `fn.dateAdd({ startDate, unit, amount, timezone? })`.

Пример: `fn.dateAdd({ startDate: f.placedAt, unit: "day", amount: 7 })` даёт `new Date("2026-03-22T10: 30: 45.123Z")`.

### fn.dateSubtract

Вычитает `amount` единиц. `fn.dateSubtract({ startDate, unit, amount, timezone? })`.

Пример: `fn.dateSubtract({ startDate: f.placedAt, unit: "month", amount: 1 })` даёт `new Date("2026-02-15T10: 30: 45.123Z")`.

### fn.dateDiff

Число границ единицы между датами (int64, `bigint`): 15 марта 23:59 и 16 марта 00:01 разделяет одна граница дня. `fn.dateDiff({ startDate, endDate, unit, timezone?, startOfWeek? })`.

Пример: `fn.dateDiff({ startDate: f.placedAt, endDate: f.shippedAt, unit: "day" })` даёт `3n`.

### fn.dateTrunc

Округляет вниз до начала единицы (или `binSize` единиц). `fn.dateTrunc({ date, unit, binSize?, timezone?, startOfWeek? })`.

Пример: `fn.dateTrunc({ date: f.placedAt, unit: "month" })` даёт `new Date("2026-03-01T00: 00: 00.000Z")`.

## Сборка, разбор и форматирование

Операторы, которые превращают дату в части или строку и обратно.

Один запрос считает сразу все операторы группы:

```ts twoslash
import { Timestamp } from "mongodb";
import { Entity, fn, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema()
class Line {
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) qty!: number;
}
@Schema({ collection: "orders" })
class Order extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) price!: number;
  @Prop(() => Number, { required: true }) quantity!: number;
  @Prop(() => Number, { required: true }) delta!: number;
  @Prop(() => Number, { required: true }) ratio!: number;
  @Prop(() => Number) discount?: number;
  @Prop(() => Date, { required: true }) placedAt!: Date;
  @Prop(() => Date, { required: true }) shippedAt!: Date;
  @Prop(() => Timestamp) stamp?: Timestamp;
  @Prop(() => [String]) tags!: string[];
  @Prop(() => [Number]) prices!: number[];
  @Prop(() => [Line]) lines!: Line[];
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
const Orders = client.db().model(Order);
// ---cut---
const [row] = await Orders.aggregate((p) =>
  p.project((f) => ({
    dateFromParts: fn.dateFromParts({ year: 2026, month: 3, day: 15 }),
    dateToParts: fn.dateToParts({ date: f.placedAt }),
    dateFromString: fn.dateFromString({ dateString: "2026-03-15", onError: null }),
    dateToString: fn.dateToString({ date: f.placedAt, format: "%Y-%m-%d" }),
    _id: 0,
  })),
);
console.log(row);
// → {dateFromParts: new Date("2026-03-15T00: 00: 00.000Z"), dateToParts: {year: 2026, month: 3, day: 15, hour: 10, minute: 30, second: 45, millisecond: 123}, dateFromString: new Date("2026-03-15T00: 00: 00.000Z"), dateToString: "2026-03-15"}
```

Ниже каждый оператор описан отдельно.

### fn.dateFromParts

Собирает дату из частей: `year` обязателен, остальные по умолчанию — начало периода. Вместо календарных частей можно передать ISO-недели (`isoWeekYear`, `isoWeek`, `isoDayOfWeek`). `fn.dateFromParts({ year, month?, day?, hour?, minute?, second?, millisecond?, timezone? })`.

Пример: `fn.dateFromParts({ year: 2026, month: 3, day: 15 })` даёт `new Date("2026-03-15T00: 00: 00.000Z")`.

### fn.dateToParts

Разбирает дату на части; с `iso8601: true` — на ISO-части (`isoWeekYear`, `isoWeek`, `isoDayOfWeek`). `fn.dateToParts({ date, timezone?, iso8601? })`.

Пример: `fn.dateToParts({ date: f.placedAt })` даёт `{year: 2026, month: 3, day: 15, hour: 10, minute: 30, second: 45, millisecond: 123}`.

### fn.dateFromString

Разбирает строку в дату. `onError` и `onNull` задают значение на неверной или пустой строке; без `onError` неверная строка — ошибка сервера. `fn.dateFromString({ dateString, format?, timezone?, onError?, onNull? })`.

Пример: `fn.dateFromString({ dateString: "2026-03-15", onError: null })` даёт `new Date("2026-03-15T00: 00: 00.000Z")`.

### fn.dateToString

Форматирует дату в строку; без `format` — ISO 8601. `onNull` заменяет `null`. `fn.dateToString({ date, format?, timezone?, onNull? })`.

Пример: `fn.dateToString({ date: f.placedAt, format: "%Y-%m-%d" })` даёт `"2026-03-15"`.

## Временные метки

Временная метка `Timestamp` — служебный тип MongoDB: пара «секунды, приращение». Операторы достают из неё части; обе части — int64.

Один запрос считает сразу все операторы группы:

```ts twoslash
import { Timestamp } from "mongodb";
import { Entity, fn, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema()
class Line {
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) qty!: number;
}
@Schema({ collection: "orders" })
class Order extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) price!: number;
  @Prop(() => Number, { required: true }) quantity!: number;
  @Prop(() => Number, { required: true }) delta!: number;
  @Prop(() => Number, { required: true }) ratio!: number;
  @Prop(() => Number) discount?: number;
  @Prop(() => Date, { required: true }) placedAt!: Date;
  @Prop(() => Date, { required: true }) shippedAt!: Date;
  @Prop(() => Timestamp) stamp?: Timestamp;
  @Prop(() => [String]) tags!: string[];
  @Prop(() => [Number]) prices!: number[];
  @Prop(() => [Line]) lines!: Line[];
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
const Orders = client.db().model(Order);
// ---cut---
const [row] = await Orders.aggregate((p) =>
  p.project((f) => ({
    tsSecond: fn.tsSecond(f.stamp),
    tsIncrement: fn.tsIncrement(f.stamp),
    _id: 0,
  })),
);
console.log(row);
// → {tsSecond: 1700000000n, tsIncrement: 5n}
```

Ниже каждый оператор описан отдельно.

### fn.tsSecond

Секунды временной метки (int64, `bigint`). `fn.tsSecond(timestamp)`.

Пример: `fn.tsSecond(f.stamp)` даёт `1700000000n`.

### fn.tsIncrement

Приращение временной метки (int64, `bigint`). `fn.tsIncrement(timestamp)`.

Пример: `fn.tsIncrement(f.stamp)` даёт `5n`.

## Часовые пояса

Части даты принимают объект `{ date, timezone }`. Один и тот же момент в Токио — уже 19 часов: `fn.hour({ date: f.placedAt, timezone: "Asia/Tokyo" })` даёт `19`, а без пояса — `10`. Пояс нужен, когда «день заказа» должен совпадать с днём покупателя, а не с днём по UTC.

## Когда не подходит

Если нужно сгруппировать заказы по месяцам, используйте [`dateTrunc`](#fndatetrunc) в `_id` стадии [`group`](./stages.mdx#group). Пропуски в ряду дат заполняет стадия [`densify`](./stages.mdx#densify), а не операторы.
