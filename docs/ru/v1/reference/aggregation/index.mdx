Справочник раздела «Агрегации» описывает каждый элемент API полностью. Что он принимает, что возвращает, какие ошибки бросает — всё здесь. Если вы ищете ответ на вопрос «как мне сделать X», начните с [руководств раздела](../../aggregation/index.mdx). Они ведут от задачи к решению, а за подробностями отсылают сюда.

Страницы идут по устройству конвейера. Сначала точки входа и стадии, потом операторы выражений по темам, в конце аккумуляторы и оконные функции. Каждый оператор `fn` описан в своём разделе `### fn.имя`.
