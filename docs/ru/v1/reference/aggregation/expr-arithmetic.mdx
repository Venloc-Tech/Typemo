На этой странице собраны арифметические операторы каталога `fn`: действия над числами, округление, степени и логарифмы, тригонометрия. Оператор — это функция, которая строит выражение, а выражение сервер вычисляет для каждой строки конвейера. Их пишут в колбэках стадий, например в [`project`](./stages.mdx#project) или [`group`](./stages.mdx#group): `(f) => fn.add(f.price, 1)`, где `f` — прокси полей строки.

Если вы только начинаете, сначала прочитайте руководство [Выражения](../../aggregation/expressions.mdx). Эта страница — справочник. Выражения пишутся только колбэком: сырой объект с `$expr` Typemo не принимает.

Все примеры используют одну модель заказа магазина.

```ts twoslash title="models/order.ts"
import { Timestamp } from "mongodb";
import { Entity, Prop, Schema } from "@venloc/typemo";

@Schema()
export class Line {
  @Prop(() => String, { required: true })
  sku!: string;

  @Prop(() => Number, { required: true })
  qty!: number;
}

@Schema({ collection: "orders" })
export class Order extends Entity {
  @Prop(() => String, { required: true })
  title!: string;

  @Prop(() => String, { required: true })
  sku!: string;

  @Prop(() => Number, { required: true })
  price!: number;

  @Prop(() => Number, { required: true })
  quantity!: number;

  @Prop(() => Number, { required: true })
  delta!: number;

  @Prop(() => Number, { required: true })
  ratio!: number;

  @Prop(() => Number)
  discount?: number;

  @Prop(() => Date, { required: true })
  placedAt!: Date;

  @Prop(() => Date, { required: true })
  shippedAt!: Date;

  @Prop(() => Timestamp)
  stamp?: Timestamp;

  @Prop(() => [String])
  tags!: string[];

  @Prop(() => [Number])
  prices!: number[];

  @Prop(() => [Line])
  lines!: Line[];
}
```

В коллекции один заказ: `title` — `"  Blue Pen  "` (с пробелами по краям), `sku` — `"PEN-001"`, `price` — 19.99, `quantity` — 3, `delta` — -5, `ratio` — 0.5, `placedAt` — 15 марта 2026, 10:30:45.123 UTC, `shippedAt` — 18 марта 2026, 08:00 UTC, `stamp` — временная метка с секундами 1700000000 и приращением 5, `tags` — `["new", "sale", "pen"]`, `prices` — `[30, 10, 20]`, `lines` — две строки (`pen`×2 и `ink`×1). Поля `discount` у заказа нет. Результаты в комментариях `// →` получены запуском на этих данных.

## Округление и модуль

Операторы, которые берут одно число и возвращают число: модуль, округление вверх и вниз. Для целого числа `ceil` и `floor` возвращают его же.

Один запрос считает сразу все операторы группы:

```ts twoslash
import { Timestamp } from "mongodb";
import { Entity, fn, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema()
class Line {
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) qty!: number;
}
@Schema({ collection: "orders" })
class Order extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) price!: number;
  @Prop(() => Number, { required: true }) quantity!: number;
  @Prop(() => Number, { required: true }) delta!: number;
  @Prop(() => Number, { required: true }) ratio!: number;
  @Prop(() => Number) discount?: number;
  @Prop(() => Date, { required: true }) placedAt!: Date;
  @Prop(() => Date, { required: true }) shippedAt!: Date;
  @Prop(() => Timestamp) stamp?: Timestamp;
  @Prop(() => [String]) tags!: string[];
  @Prop(() => [Number]) prices!: number[];
  @Prop(() => [Line]) lines!: Line[];
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
const Orders = client.db().model(Order);
// ---cut---
const [row] = await Orders.aggregate((p) =>
  p.project((f) => ({
    abs: fn.abs(f.delta),
    ceil: fn.ceil(f.price),
    floor: fn.floor(f.price),
    round: fn.round(f.price, 1),
    trunc: fn.trunc(f.price, 1),
    _id: 0,
  })),
);
console.log(row);
// → {abs: 5, ceil: 20, floor: 19, round: 20, trunc: 19.9}
```

Ниже каждый оператор описан отдельно.

### fn.abs

Модуль числа. `fn.abs(x)`.

Пример: `fn.abs(f.delta)` даёт `5`.

### fn.ceil

Ближайшее целое не меньше числа. `fn.ceil(x)`.

Пример: `fn.ceil(f.price)` даёт `20`.

### fn.floor

Ближайшее целое не больше числа. `fn.floor(x)`.

Пример: `fn.floor(f.price)` даёт `19`.

### fn.round

Округляет до `place` знаков после запятой (по умолчанию до целого); отрицательный `place` округляет разряды слева от запятой. При ровно половине округляет к чётному. `fn.round(x, place?)`.

Пример: `fn.round(f.price, 1)` даёт `20`.

### fn.trunc

Отбрасывает дробную часть; с `place` — знаки после указанного. `fn.trunc(x, place?)`.

Пример: `fn.trunc(f.price, 1)` даёт `19.9`.

## Сложение, вычитание, умножение, деление

Четыре действия арифметики. Если хотя бы один аргумент `null` или отсутствует, результат `null`: пропущенное значение не превращается в ноль. Тип результата следует за аргументами: `number`, `bigint` или `Decimal128`.

Один запрос считает сразу все операторы группы:

```ts twoslash
import { Timestamp } from "mongodb";
import { Entity, fn, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema()
class Line {
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) qty!: number;
}
@Schema({ collection: "orders" })
class Order extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) price!: number;
  @Prop(() => Number, { required: true }) quantity!: number;
  @Prop(() => Number, { required: true }) delta!: number;
  @Prop(() => Number, { required: true }) ratio!: number;
  @Prop(() => Number) discount?: number;
  @Prop(() => Date, { required: true }) placedAt!: Date;
  @Prop(() => Date, { required: true }) shippedAt!: Date;
  @Prop(() => Timestamp) stamp?: Timestamp;
  @Prop(() => [String]) tags!: string[];
  @Prop(() => [Number]) prices!: number[];
  @Prop(() => [Line]) lines!: Line[];
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
const Orders = client.db().model(Order);
// ---cut---
const [row] = await Orders.aggregate((p) =>
  p.project((f) => ({
    add: fn.add(f.price, f.quantity, 1),
    subtract: fn.subtract(f.shippedAt, f.placedAt),
    multiply: fn.multiply(f.price, f.quantity),
    divide: fn.divide(f.price, f.quantity),
    mod: fn.mod(f.quantity, 2),
    _id: 0,
  })),
);
console.log(row);
// → {add: 23.99, subtract: 250154877n, multiply: 59.97, divide: 6.663333333333333, mod: 1}
```

Ниже каждый оператор описан отдельно.

### fn.add

Сумма двух и более чисел. К дате можно прибавить число миллисекунд: результат — дата. `fn.add(a, b, …)`.

Пример: `fn.add(f.price, f.quantity, 1)` даёт `23.99`.

### fn.subtract

Разность. Две даты дают разницу в миллисекундах (int64), дата минус число — дату. `fn.subtract(a, b)`.

Пример: `fn.subtract(f.shippedAt, f.placedAt)` даёт `250154877n`.

### fn.multiply

Произведение двух и более чисел. `fn.multiply(a, b, …)`.

Пример: `fn.multiply(f.price, f.quantity)` даёт `59.97`.

### fn.divide

Частное. Деление на ноль — ошибка сервера. `fn.divide(a, b)`.

Пример: `fn.divide(f.price, f.quantity)` даёт `6.663333333333333`.

### fn.mod

Остаток от деления. `fn.mod(a, b)`.

Пример: `fn.mod(f.quantity, 2)` даёт `1`.

## Степени и логарифмы

Операторы, которые всегда возвращают дробное число (`double`), либо `Decimal128` для аргумента `Decimal128`.

Один запрос считает сразу все операторы группы:

```ts twoslash
import { Timestamp } from "mongodb";
import { Entity, fn, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema()
class Line {
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) qty!: number;
}
@Schema({ collection: "orders" })
class Order extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) price!: number;
  @Prop(() => Number, { required: true }) quantity!: number;
  @Prop(() => Number, { required: true }) delta!: number;
  @Prop(() => Number, { required: true }) ratio!: number;
  @Prop(() => Number) discount?: number;
  @Prop(() => Date, { required: true }) placedAt!: Date;
  @Prop(() => Date, { required: true }) shippedAt!: Date;
  @Prop(() => Timestamp) stamp?: Timestamp;
  @Prop(() => [String]) tags!: string[];
  @Prop(() => [Number]) prices!: number[];
  @Prop(() => [Line]) lines!: Line[];
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
const Orders = client.db().model(Order);
// ---cut---
const [row] = await Orders.aggregate((p) =>
  p.project((f) => ({
    sqrt: fn.sqrt(f.quantity),
    pow: fn.pow(f.quantity, 2),
    exp: fn.exp(1),
    ln: fn.ln(10),
    log: fn.log(8, 2),
    log10: fn.log10(1000),
    _id: 0,
  })),
);
console.log(row);
// → {sqrt: 1.7320508075688772, pow: 9, exp: 2.718281828459045, ln: 2.302585092994046, log: 3, log10: 3}
```

Ниже каждый оператор описан отдельно.

### fn.sqrt

Квадратный корень. `fn.sqrt(x)`.

Пример: `fn.sqrt(f.quantity)` даёт `1.7320508075688772`.

### fn.pow

Возведение в степень. `fn.pow(основание, показатель)`.

Пример: `fn.pow(f.quantity, 2)` даёт `9`.

### fn.exp

Число e в степени x. `fn.exp(x)`.

Пример: `fn.exp(1)` даёт `2.718281828459045`.

### fn.ln

Натуральный логарифм. `fn.ln(x)`.

Пример: `fn.ln(10)` даёт `2.302585092994046`.

### fn.log

Логарифм по основанию. `fn.log(x, base)`.

Пример: `fn.log(8, 2)` даёт `3`.

### fn.log10

Десятичный логарифм. `fn.log10(x)`.

Пример: `fn.log10(1000)` даёт `3`.

## Тригонометрия

Тригонометрические функции принимают радианы и возвращают дробное число. Значение вне области определения (например, `asin(2)`) сервер отвергает ошибкой.

Один запрос считает сразу все операторы группы:

```ts twoslash
import { Timestamp } from "mongodb";
import { Entity, fn, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema()
class Line {
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) qty!: number;
}
@Schema({ collection: "orders" })
class Order extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) price!: number;
  @Prop(() => Number, { required: true }) quantity!: number;
  @Prop(() => Number, { required: true }) delta!: number;
  @Prop(() => Number, { required: true }) ratio!: number;
  @Prop(() => Number) discount?: number;
  @Prop(() => Date, { required: true }) placedAt!: Date;
  @Prop(() => Date, { required: true }) shippedAt!: Date;
  @Prop(() => Timestamp) stamp?: Timestamp;
  @Prop(() => [String]) tags!: string[];
  @Prop(() => [Number]) prices!: number[];
  @Prop(() => [Line]) lines!: Line[];
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
const Orders = client.db().model(Order);
// ---cut---
const [row] = await Orders.aggregate((p) =>
  p.project((f) => ({
    sin: fn.sin(f.ratio),
    cos: fn.cos(f.ratio),
    tan: fn.tan(f.ratio),
    asin: fn.asin(f.ratio),
    acos: fn.acos(f.ratio),
    atan: fn.atan(f.ratio),
    atan2: fn.atan2(1, 1),
    sinh: fn.sinh(f.ratio),
    cosh: fn.cosh(f.ratio),
    tanh: fn.tanh(f.ratio),
    asinh: fn.asinh(f.ratio),
    acosh: fn.acosh(2),
    atanh: fn.atanh(f.ratio),
    degreesToRadians: fn.degreesToRadians(180),
    radiansToDegrees: fn.radiansToDegrees(1),
    sigmoid: fn.sigmoid(0),
    _id: 0,
  })),
);
console.log(row);
// → {sin: 0.479425538604203, cos: 0.8775825618903728, tan: 0.5463024898437905, asin: 0.5235987755982988, acos: 1.0471975511965976, atan: 0.46364760900080615, atan2: 0.7853981633974483, sinh: 0.5210953054937474, cosh: 1.1276259652063807, tanh: 0.46211715726000974, asinh: 0.48121182505960347, acosh: 1.3169578969248166, atanh: 0.5493061443340549, degreesToRadians: 3.141592653589793, radiansToDegrees: 57.29577951308232, sigmoid: 0.5}
```

Ниже каждый оператор описан отдельно.

### fn.sin

Синус. `fn.sin(x)`.

Пример: `fn.sin(f.ratio)` даёт `0.479425538604203`.

### fn.cos

Косинус. `fn.cos(x)`.

Пример: `fn.cos(f.ratio)` даёт `0.8775825618903728`.

### fn.tan

Тангенс. `fn.tan(x)`.

Пример: `fn.tan(f.ratio)` даёт `0.5463024898437905`.

### fn.asin

Арксинус, аргумент от -1 до 1. `fn.asin(x)`.

Пример: `fn.asin(f.ratio)` даёт `0.5235987755982988`.

### fn.acos

Арккосинус, аргумент от -1 до 1. `fn.acos(x)`.

Пример: `fn.acos(f.ratio)` даёт `1.0471975511965976`.

### fn.atan

Арктангенс. `fn.atan(x)`.

Пример: `fn.atan(f.ratio)` даёт `0.46364760900080615`.

### fn.atan2

Арктангенс y/x с учётом четверти. `fn.atan2(y, x)`.

Пример: `fn.atan2(1, 1)` даёт `0.7853981633974483`.

### fn.sinh

Гиперболический синус. `fn.sinh(x)`.

Пример: `fn.sinh(f.ratio)` даёт `0.5210953054937474`.

### fn.cosh

Гиперболический косинус. `fn.cosh(x)`.

Пример: `fn.cosh(f.ratio)` даёт `1.1276259652063807`.

### fn.tanh

Гиперболический тангенс. `fn.tanh(x)`.

Пример: `fn.tanh(f.ratio)` даёт `0.46211715726000974`.

### fn.asinh

Обратный гиперболический синус. `fn.asinh(x)`.

Пример: `fn.asinh(f.ratio)` даёт `0.48121182505960347`.

### fn.acosh

Обратный гиперболический косинус, аргумент не меньше 1. `fn.acosh(x)`.

Пример: `fn.acosh(2)` даёт `1.3169578969248166`.

### fn.atanh

Обратный гиперболический тангенс, аргумент от -1 до 1. `fn.atanh(x)`.

Пример: `fn.atanh(f.ratio)` даёт `0.5493061443340549`.

### fn.degreesToRadians

Градусы в радианы. `fn.degreesToRadians(x)`.

Пример: `fn.degreesToRadians(180)` даёт `3.141592653589793`.

### fn.radiansToDegrees

Радианы в градусы. `fn.radiansToDegrees(x)`.

Пример: `fn.radiansToDegrees(1)` даёт `57.29577951308232`.

### fn.sigmoid

Сигмоида `1 / (1 + e^-x)`: сжимает любое число в интервал от 0 до 1. `fn.sigmoid(x)`.

Пример: `fn.sigmoid(0)` даёт `0.5`.

## Особые случаи

Если аргумент отсутствует или `null`, результат — `null`: `fn.add(f.price, f.discount)` для заказа без `discount` даёт `null`, а не 19.99. Деление на ноль сервер отвергает:

```text
ServerError: can't $divide by zero (code 2 BadValue)
```

`fn.round` при ровно половине округляет к чётному: `fn.round(2.5)` даёт 2, `fn.round(3.5)` — 4, а `fn.round(1234, -2)` — 1200. Не полагайтесь на округление «от нуля».

## Когда не подходит

Если нужно свернуть числа по группе строк, а не считать в одной строке, используйте аккумуляторы [`fn.sum`, `fn.avg`](./accumulators.mdx) в [`group`](./stages.mdx#group). Приведение типа (`toInt`, `toDouble`) — на странице [Выражения: преобразование типов](./expr-conversion.mdx).
