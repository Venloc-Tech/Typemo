Здесь собраны арифметические операторы каталога `fn`. Они считают числа, округляют, возводят в степень, берут логарифмы и тригонометрию. Оператор строит выражение, а сервер вычисляет его для каждой строки конвейера. Пишут операторы в колбэках стадий, например в [`project`](./stages.mdx#project) или [`group`](./stages.mdx#group), так — `(f) => fn.add(f.price, 1)`. Здесь `f` — прокси полей строки.

Это справочник. Если вы только начинаете, сначала прочитайте руководство [Выражения](../../aggregation/expressions.mdx). Выражения пишутся только колбэком, сырой объект с `$expr` Typemo не принимает.

Во всех примерах одна и та же модель заказа магазина.

```ts twoslash title="models/order.ts"
import { Timestamp } from "mongodb";
import { Entity, Prop, Schema } from "@venloc/typemo";

@Schema()
export class Line {
  @Prop(() => String, { required: true })
  sku!: string;

  @Prop(() => Number, { required: true })
  qty!: number;
}

@Schema({ collection: "orders" })
export class Order extends Entity {
  @Prop(() => String, { required: true })
  title!: string;

  @Prop(() => String, { required: true })
  sku!: string;

  @Prop(() => Number, { required: true })
  price!: number;

  @Prop(() => Number, { required: true })
  quantity!: number;

  @Prop(() => Number, { required: true })
  delta!: number;

  @Prop(() => Number, { required: true })
  ratio!: number;

  @Prop(() => Number)
  discount?: number;

  @Prop(() => Date, { required: true })
  placedAt!: Date;

  @Prop(() => Date, { required: true })
  shippedAt!: Date;

  @Prop(() => Timestamp)
  stamp?: Timestamp;

  @Prop(() => [String])
  tags!: string[];

  @Prop(() => [Number])
  prices!: number[];

  @Prop(() => [Line])
  lines!: Line[];
}
```

В коллекции лежит один заказ.

- `title` — `"  Blue Pen  "` с пробелами по краям, `sku` — `"PEN-001"`.
- `price` — 19.99, `quantity` — 3, `delta` — -5, `ratio` — 0.5.
- `placedAt` — 15 марта 2026, 10 ч 30 мин 45,123 с UTC, `shippedAt` — 18 марта 2026, 8 ч 00 мин UTC.
- `stamp` — временная метка с секундами 1700000000 и приращением 5.
- `tags` — `["new", "sale", "pen"]`, `prices` — `[30, 10, 20]`.
- `lines` — две строки, `pen`×2 и `ink`×1.

Поля `discount` у заказа нет. Результаты в комментариях `// →` получены запуском на этих данных.

## Округление и модуль [#rounding]

Эти операторы берут одно число и возвращают число. Для целого `ceil` и `floor` возвращают то же самое целое.

Один запрос считает все операторы группы сразу.

```ts twoslash
import { Timestamp } from "mongodb";
import { Entity, fn, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema()
class Line {
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) qty!: number;
}
@Schema({ collection: "orders" })
class Order extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) price!: number;
  @Prop(() => Number, { required: true }) quantity!: number;
  @Prop(() => Number, { required: true }) delta!: number;
  @Prop(() => Number, { required: true }) ratio!: number;
  @Prop(() => Number) discount?: number;
  @Prop(() => Date, { required: true }) placedAt!: Date;
  @Prop(() => Date, { required: true }) shippedAt!: Date;
  @Prop(() => Timestamp) stamp?: Timestamp;
  @Prop(() => [String]) tags!: string[];
  @Prop(() => [Number]) prices!: number[];
  @Prop(() => [Line]) lines!: Line[];
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
const Orders = client.db().model(Order);
// ---cut---
const [row] = await Orders.aggregate((p) =>
  p.project((f) => ({
    abs: fn.abs(f.delta),
    ceil: fn.ceil(f.price),
    floor: fn.floor(f.price),
    round: fn.round(f.price, 1),
    trunc: fn.trunc(f.price, 1),
    _id: 0,
  })),
);
console.log(row);
// → {abs: 5, ceil: 20, floor: 19, round: 20, trunc: 19.9}
```

Ниже каждый оператор описан отдельно.

### fn.abs [#fn.abs]

Модуль числа. `fn.abs(x)`.

Например, `fn.abs(f.delta)` даёт `5`.

### fn.ceil [#fn.ceil]

Ближайшее целое, не меньшее числа. `fn.ceil(x)`.

Например, `fn.ceil(f.price)` даёт `20`.

### fn.floor [#fn.floor]

Ближайшее целое, не большее числа. `fn.floor(x)`.

Например, `fn.floor(f.price)` даёт `19`.

### fn.round [#fn.round]

Округляет до `place` знаков после запятой, по умолчанию до целого. Отрицательный `place` округляет разряды слева от запятой. Ровно половину округляет к чётному. `fn.round(x, place?)`.

Например, `fn.round(f.price, 1)` даёт `20`.

### fn.trunc [#fn.trunc]

Отбрасывает дробную часть. С `place` оставляет столько знаков после запятой. `fn.trunc(x, place?)`.

Например, `fn.trunc(f.price, 1)` даёт `19.9`.

## Сложение, вычитание, умножение, деление [#arithmetic]

Четыре действия арифметики. Если хоть один аргумент `null` или отсутствует, результат тоже `null`, а пропуск в ноль не превращается. Тип результата зависит от аргументов — `number`, `bigint` или `Decimal128`.

Один запрос считает все операторы группы сразу.

```ts twoslash
import { Timestamp } from "mongodb";
import { Entity, fn, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema()
class Line {
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) qty!: number;
}
@Schema({ collection: "orders" })
class Order extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) price!: number;
  @Prop(() => Number, { required: true }) quantity!: number;
  @Prop(() => Number, { required: true }) delta!: number;
  @Prop(() => Number, { required: true }) ratio!: number;
  @Prop(() => Number) discount?: number;
  @Prop(() => Date, { required: true }) placedAt!: Date;
  @Prop(() => Date, { required: true }) shippedAt!: Date;
  @Prop(() => Timestamp) stamp?: Timestamp;
  @Prop(() => [String]) tags!: string[];
  @Prop(() => [Number]) prices!: number[];
  @Prop(() => [Line]) lines!: Line[];
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
const Orders = client.db().model(Order);
// ---cut---
const [row] = await Orders.aggregate((p) =>
  p.project((f) => ({
    add: fn.add(f.price, f.quantity, 1),
    subtract: fn.subtract(f.shippedAt, f.placedAt),
    multiply: fn.multiply(f.price, f.quantity),
    divide: fn.divide(f.price, f.quantity),
    mod: fn.mod(f.quantity, 2),
    _id: 0,
  })),
);
console.log(row);
// → {add: 23.99, subtract: 250154877n, multiply: 59.97, divide: 6.663333333333333, mod: 1}
```

Ниже каждый оператор описан отдельно.

### fn.add [#fn.add]

Сумма двух и более чисел. Если прибавить к дате число миллисекунд, получится дата. `fn.add(a, b, …)`.

Например, `fn.add(f.price, f.quantity, 1)` даёт `23.99`.

### fn.subtract [#fn.subtract]

Разность. Две даты дают разницу в миллисекундах (int64), а дата минус число — дату. `fn.subtract(a, b)`.

Например, `fn.subtract(f.shippedAt, f.placedAt)` даёт `250154877n`.

### fn.multiply [#fn.multiply]

Произведение двух и более чисел. `fn.multiply(a, b, …)`.

Например, `fn.multiply(f.price, f.quantity)` даёт `59.97`.

### fn.divide [#fn.divide]

Частное. Деление на ноль сервер отвергает ошибкой. `fn.divide(a, b)`.

Например, `fn.divide(f.price, f.quantity)` даёт `6.663333333333333`.

### fn.mod [#fn.mod]

Остаток от деления. `fn.mod(a, b)`.

Например, `fn.mod(f.quantity, 2)` даёт `1`.

## Степени и логарифмы [#powers-and-logs]

Эти операторы всегда возвращают дробное число (`double`), а для аргумента `Decimal128` — `Decimal128`.

Один запрос считает все операторы группы сразу.

```ts twoslash
import { Timestamp } from "mongodb";
import { Entity, fn, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema()
class Line {
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) qty!: number;
}
@Schema({ collection: "orders" })
class Order extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) price!: number;
  @Prop(() => Number, { required: true }) quantity!: number;
  @Prop(() => Number, { required: true }) delta!: number;
  @Prop(() => Number, { required: true }) ratio!: number;
  @Prop(() => Number) discount?: number;
  @Prop(() => Date, { required: true }) placedAt!: Date;
  @Prop(() => Date, { required: true }) shippedAt!: Date;
  @Prop(() => Timestamp) stamp?: Timestamp;
  @Prop(() => [String]) tags!: string[];
  @Prop(() => [Number]) prices!: number[];
  @Prop(() => [Line]) lines!: Line[];
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
const Orders = client.db().model(Order);
// ---cut---
const [row] = await Orders.aggregate((p) =>
  p.project((f) => ({
    sqrt: fn.sqrt(f.quantity),
    pow: fn.pow(f.quantity, 2),
    exp: fn.exp(1),
    ln: fn.ln(10),
    log: fn.log(8, 2),
    log10: fn.log10(1000),
    _id: 0,
  })),
);
console.log(row);
// → {sqrt: 1.7320508075688772, pow: 9, exp: 2.718281828459045, ln: 2.302585092994046, log: 3, log10: 3}
```

Ниже каждый оператор описан отдельно.

### fn.sqrt [#fn.sqrt]

Квадратный корень. `fn.sqrt(x)`.

Например, `fn.sqrt(f.quantity)` даёт `1.7320508075688772`.

### fn.pow [#fn.pow]

Возведение в степень. `fn.pow(основание, показатель)`.

Например, `fn.pow(f.quantity, 2)` даёт `9`.

### fn.exp [#fn.exp]

Число e в степени x. `fn.exp(x)`.

Например, `fn.exp(1)` даёт `2.718281828459045`.

### fn.ln [#fn.ln]

Натуральный логарифм. `fn.ln(x)`.

Например, `fn.ln(10)` даёт `2.302585092994046`.

### fn.log [#fn.log]

Логарифм по заданному основанию. `fn.log(x, base)`.

Например, `fn.log(8, 2)` даёт `3`.

### fn.log10 [#fn.log10]

Десятичный логарифм. `fn.log10(x)`.

Например, `fn.log10(1000)` даёт `3`.

## Тригонометрия [#trigonometry]

Тригонометрические функции принимают радианы и возвращают дробное число. Если значение вне области определения, например `asin(2)`, сервер отвечает ошибкой.

Один запрос считает все операторы группы сразу.

```ts twoslash
import { Timestamp } from "mongodb";
import { Entity, fn, Prop, Schema, TypemoClient } from "@venloc/typemo";
@Schema()
class Line {
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) qty!: number;
}
@Schema({ collection: "orders" })
class Order extends Entity {
  @Prop(() => String, { required: true }) title!: string;
  @Prop(() => String, { required: true }) sku!: string;
  @Prop(() => Number, { required: true }) price!: number;
  @Prop(() => Number, { required: true }) quantity!: number;
  @Prop(() => Number, { required: true }) delta!: number;
  @Prop(() => Number, { required: true }) ratio!: number;
  @Prop(() => Number) discount?: number;
  @Prop(() => Date, { required: true }) placedAt!: Date;
  @Prop(() => Date, { required: true }) shippedAt!: Date;
  @Prop(() => Timestamp) stamp?: Timestamp;
  @Prop(() => [String]) tags!: string[];
  @Prop(() => [Number]) prices!: number[];
  @Prop(() => [Line]) lines!: Line[];
}
const client = await TypemoClient.connect("mongodb://localhost:27017", { dbName: "shop" });
const Orders = client.db().model(Order);
// ---cut---
const [row] = await Orders.aggregate((p) =>
  p.project((f) => ({
    sin: fn.sin(f.ratio),
    cos: fn.cos(f.ratio),
    tan: fn.tan(f.ratio),
    asin: fn.asin(f.ratio),
    acos: fn.acos(f.ratio),
    atan: fn.atan(f.ratio),
    atan2: fn.atan2(1, 1),
    sinh: fn.sinh(f.ratio),
    cosh: fn.cosh(f.ratio),
    tanh: fn.tanh(f.ratio),
    asinh: fn.asinh(f.ratio),
    acosh: fn.acosh(2),
    atanh: fn.atanh(f.ratio),
    degreesToRadians: fn.degreesToRadians(180),
    radiansToDegrees: fn.radiansToDegrees(1),
    sigmoid: fn.sigmoid(0),
    _id: 0,
  })),
);
console.log(row);
// → {sin: 0.479425538604203, cos: 0.8775825618903728, tan: 0.5463024898437905, asin: 0.5235987755982988, acos: 1.0471975511965976, atan: 0.46364760900080615, atan2: 0.7853981633974483, sinh: 0.5210953054937474, cosh: 1.1276259652063807, tanh: 0.46211715726000974, asinh: 0.48121182505960347, acosh: 1.3169578969248166, atanh: 0.5493061443340549, degreesToRadians: 3.141592653589793, radiansToDegrees: 57.29577951308232, sigmoid: 0.5}
```

Ниже каждый оператор описан отдельно.

### fn.sin [#fn.sin]

Синус. `fn.sin(x)`.

Например, `fn.sin(f.ratio)` даёт `0.479425538604203`.

### fn.cos [#fn.cos]

Косинус. `fn.cos(x)`.

Например, `fn.cos(f.ratio)` даёт `0.8775825618903728`.

### fn.tan [#fn.tan]

Тангенс. `fn.tan(x)`.

Например, `fn.tan(f.ratio)` даёт `0.5463024898437905`.

### fn.asin [#fn.asin]

Арксинус. Аргумент от -1 до 1. `fn.asin(x)`.

Например, `fn.asin(f.ratio)` даёт `0.5235987755982988`.

### fn.acos [#fn.acos]

Арккосинус. Аргумент от -1 до 1. `fn.acos(x)`.

Например, `fn.acos(f.ratio)` даёт `1.0471975511965976`.

### fn.atan [#fn.atan]

Арктангенс. `fn.atan(x)`.

Например, `fn.atan(f.ratio)` даёт `0.46364760900080615`.

### fn.atan2 [#fn.atan2]

Арктангенс y/x с учётом четверти. `fn.atan2(y, x)`.

Например, `fn.atan2(1, 1)` даёт `0.7853981633974483`.

### fn.sinh [#fn.sinh]

Гиперболический синус. `fn.sinh(x)`.

Например, `fn.sinh(f.ratio)` даёт `0.5210953054937474`.

### fn.cosh [#fn.cosh]

Гиперболический косинус. `fn.cosh(x)`.

Например, `fn.cosh(f.ratio)` даёт `1.1276259652063807`.

### fn.tanh [#fn.tanh]

Гиперболический тангенс. `fn.tanh(x)`.

Например, `fn.tanh(f.ratio)` даёт `0.46211715726000974`.

### fn.asinh [#fn.asinh]

Обратный гиперболический синус. `fn.asinh(x)`.

Например, `fn.asinh(f.ratio)` даёт `0.48121182505960347`.

### fn.acosh [#fn.acosh]

Обратный гиперболический косинус. Аргумент не меньше 1. `fn.acosh(x)`.

Например, `fn.acosh(2)` даёт `1.3169578969248166`.

### fn.atanh [#fn.atanh]

Обратный гиперболический тангенс. Аргумент от -1 до 1. `fn.atanh(x)`.

Например, `fn.atanh(f.ratio)` даёт `0.5493061443340549`.

### fn.degreesToRadians [#fn.degrees-to-radians]

Переводит градусы в радианы. `fn.degreesToRadians(x)`.

Например, `fn.degreesToRadians(180)` даёт `3.141592653589793`.

### fn.radiansToDegrees [#fn.radians-to-degrees]

Переводит радианы в градусы. `fn.radiansToDegrees(x)`.

Например, `fn.radiansToDegrees(1)` даёт `57.29577951308232`.

### fn.sigmoid [#fn.sigmoid]

Сигмоида `1 / (1 + e^-x)`. Любое число она сжимает в интервал от 0 до 1. `fn.sigmoid(x)`.

Например, `fn.sigmoid(0)` даёт `0.5`.

## Особые случаи [#special-cases]

Если аргумент отсутствует или `null`, результат — `null`. Для заказа без `discount` выражение `fn.add(f.price, f.discount)` даёт `null`, а не 19.99. Деление на ноль сервер отвергает.

```text
ServerError: can't $divide by zero (code 2 BadValue)
```

`fn.round` округляет ровно половину к чётному. `fn.round(2.5)` даёт 2, `fn.round(3.5)` — 4, а `fn.round(1234, -2)` — 1200. На округление «от нуля» не рассчитывайте.

## Когда не подходит [#when-not-to-use]

Чтобы свернуть числа по группе строк, а не считать в одной строке, берите аккумуляторы [`fn.sum`, `fn.avg`](./accumulators.mdx) в [`group`](./stages.mdx#group). Приведение типа (`toInt`, `toDouble`) описано на странице про [преобразование типов](./expr-conversion.mdx).
