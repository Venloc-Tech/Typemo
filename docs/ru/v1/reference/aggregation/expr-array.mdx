Здесь собраны операторы каталога `fn` для работы с массивами внутри одной строки. Они достают элементы по индексу, режут срезы, считают множества и умеют `map`, `filter` и `reduce`. Сервер вычисляет их для каждой строки в стадиях вроде [`project`](./stages.mdx#project) или [`addFields`](./stages.mdx#add-fields).

Это справочник. Если вы только начинаете, сначала прочитайте руководство [Выражения](../../aggregation/expressions.mdx). Выражения пишутся только колбэком, сырой объект с `$expr` Typemo не принимает.

Во всех примерах одна и та же модель заказа магазина.

<Snippet id="reference/aggregation/expr-arithmetic/intro" title="models/order.ts" twoslash />

В коллекции лежит один заказ.

- `title` — `"  Blue Pen  "` с пробелами по краям, `sku` — `"PEN-001"`.
- `price` — 19.99, `quantity` — 3, `delta` — -5, `ratio` — 0.5.
- `placedAt` — 15 марта 2026, 10 ч 30 мин 45,123 с UTC, `shippedAt` — 18 марта 2026, 8 ч 00 мин UTC.
- `stamp` — временная метка с секундами 1700000000 и приращением 5.
- `tags` — `["new", "sale", "pen"]`, `prices` — `[30, 10, 20]`.
- `lines` — две строки, `pen`×2 и `ink`×1.

Поля `discount` у заказа нет. Результаты в комментариях `// →` получены запуском на этих данных.

## Размер, порядок и доступ [#size-order-access]

Эти операторы читают массив и не меняют его. Для `null` и отсутствующего поля большинство из них возвращает `null`, а `size` на не-массиве падает.

Один запрос считает все операторы группы сразу.

<Snippet id="reference/aggregation/expr-array/size-order-access" twoslash />

Ниже каждый оператор описан отдельно.

### fn.size [#fn.size]

Число элементов. На не-массиве сервер отвечает ошибкой. `fn.size(array)`.

Например, `fn.size(f.tags)` даёт `3`.

### fn.arrayElemAt [#fn.array-elem-at]

Элемент по индексу. Отрицательный индекс считается с конца, а выход за границы даёт отсутствующее значение. `fn.arrayElemAt(array, index)`.

Например, `fn.arrayElemAt(f.tags, 0)` даёт `"new"`.

### fn.indexOfArray [#fn.index-of-array]

Индекс значения, а если его нет — `-1`. `fn.indexOfArray(array, значение, от?, до?)`.

Например, `fn.indexOfArray(f.tags, "sale")` даёт `1`.

### fn.slice [#fn.slice]

Срез. Берёт первые `n` элементов (при отрицательном `n` — последние) либо `n` элементов с заданной позиции. `fn.slice(array, n)` и `fn.slice(array, позиция, n)`.

Например, `fn.slice(f.tags, 1, 1)` даёт `["sale"]`.

### fn.reverseArray [#fn.reverse-array]

Массив в обратном порядке. `fn.reverseArray(array)`.

Например, `fn.reverseArray(f.tags)` даёт `["pen", "sale", "new"]`.

### fn.sortArray [#fn.sort-array]

Сортирует массив. Для чисел и строк `sortBy` равен `1` или `-1`, для документов это объект по полям. `fn.sortArray({ input, sortBy })`.

Например, `fn.sortArray({ input: f.prices, sortBy: 1 })` даёт `[10, 20, 30]`.

### fn.range [#fn.range]

Целые числа от `start` до `end`, сам `end` не входит. Шаг `step` по умолчанию равен 1. `fn.range(start, end, step?)`.

Например, `fn.range(0, 5, 2)` даёт `[0, 2, 4]`.

## Объединение и множества [#union-and-sets]

Для множеств массив — это набор уникальных значений без порядка. В результате `setUnion` и похожих операторов нет повторов, а порядок сервер не обещает.

Один запрос считает все операторы группы сразу.

<Snippet id="reference/aggregation/expr-array/union-and-sets" twoslash />

Ниже каждый оператор описан отдельно.

### fn.concatArrays [#fn.concat-arrays]

Склеивает массивы. `fn.concatArrays(a, b, …)`.

Например, `fn.concatArrays(f.tags, ["x"])` даёт `["new", "sale", "pen", "x"]`.

### fn.setUnion [#fn.set-union]

Объединение множеств. `fn.setUnion(a, b, …)`.

Например, `fn.setUnion(f.tags, ["sale", "big"])` даёт `["big", "new", "pen", "sale"]`.

### fn.setIntersection [#fn.set-intersection]

Пересечение множеств. `fn.setIntersection(a, b, …)`.

Например, `fn.setIntersection(f.tags, ["sale", "x"])` даёт `["sale"]`.

### fn.setDifference [#fn.set-difference]

Элементы первого массива, которых нет во втором. `fn.setDifference(a, b)`.

Например, `fn.setDifference(f.tags, ["sale"])` даёт `["new", "pen"]`.

### fn.setIsSubset [#fn.set-is-subset]

Проверяет, что каждый элемент первого массива есть во втором. `fn.setIsSubset(a, b)`.

Например, `fn.setIsSubset(["sale"], f.tags)` даёт `true`.

### fn.setEquals [#fn.set-equals]

Проверяет, что множества состоят из одних и тех же значений. `fn.setEquals(a, b, …)`.

Например, `fn.setEquals(f.tags, ["pen", "sale", "new"])` даёт `true`.

### fn.zip [#fn.zip]

Транспонирует массивы и собирает пары элементов с одним индексом. С `useLongestLength` короткие массивы добиваются значениями `defaults`. `fn.zip({ inputs, useLongestLength?, defaults? })`.

Например, `fn.zip({ inputs: [f.tags, f.prices] })` даёт `[["new", 30], ["sale", 10], ["pen", 20]]`.

## Проверки и преобразования [#validation-and-transforms]

Эти операторы считают по элементам. `map` применяет выражение к каждому, `filter` оставляет подходящие, `reduce` сворачивает массив в одно значение. Внутри колбэка элемент — прокси, как поле `f`.

Один запрос считает все операторы группы сразу.

<Snippet id="reference/aggregation/expr-array/validation-and-transforms" twoslash />

Ниже каждый оператор описан отдельно.

### fn.allElementsTrue [#fn.all-elements-true]

Проверяет, что все элементы истинны. Пустой массив даёт `true`. `fn.allElementsTrue(array)`.

Например, `fn.allElementsTrue(f.prices)` даёт `true`.

### fn.anyElementTrue [#fn.any-element-true]

Проверяет, что истинен хотя бы один элемент. Пустой массив даёт `false`. `fn.anyElementTrue(array)`.

Например, `fn.anyElementTrue(f.prices)` даёт `true`.

### fn.map [#fn.map]

Применяет выражение к каждому элементу. `fn.map({ input, in: (item) => … })`.

Например, `fn.map({ input: f.prices, in: (price) => fn.multiply(price, 2) })` даёт `[60, 20, 40]`.

### fn.filter [#fn.filter]

Оставляет элементы, для которых `cond` истинно. `limit` ограничивает их число. `fn.filter({ input, cond: (item) => …, limit? })`.

Например, `fn.filter({ input: f.prices, cond: (price) => fn.gt(price, 15) })` даёт `[30, 20]`.

### fn.reduce [#fn.reduce]

Сворачивает массив. Тип результата совпадает с типом `initialValue`. `fn.reduce({ input, initialValue, in: (acc, item) => … })`.

Например, `fn.reduce({ input: f.prices, initialValue: 0, in: (acc, price) => fn.add(acc, price) })` даёт `60`.

### fn.arrayToObject [#fn.array-to-object]

Превращает массив пар `{ k, v }` или `[k, v]` в документ. `fn.arrayToObject(array)`.

Например, `fn.arrayToObject(fn.map({ input: f.lines, in: (line) => ({ k: line.sku, v: line.qty }) }))` даёт `{pen: 2, ink: 1}`.

## Особые случаи [#special-cases]

`fn.size` на не-массиве сервер отвергает. Для строки ответ такой — `The argument to $size must be an array, but was of type: string`. Поэтому `size` принимает только поля-массивы, и вызов над строкой компилятор остановит.

## Когда не подходит [#when-not-to-use]

Чтобы превратить элементы массива в отдельные строки, берите стадию [`unwind`](./stages.mdx#unwind). Чтобы собрать значения из многих строк в массив, берите аккумуляторы `fn.push` и `fn.addToSet` в [`group`](./stages.mdx#group).
